# 地图设计（Map Design）

地图 = **一份 yaml 里的静态障碍几何 + 作业区**。物理世界、空中安全层、感知先验、感知栅格、
复位校验**全部由它派生**。本技能是"怎么安全地改这份几何"的操作手册，**不是约束**：
约束只引用 [契约真源](../../../docs/adr/0020-package-boundaries-and-runtime-topology.md#hard-constraints)，几何 schema 的唯一出口是
[`world_map.py`](../../../src/agc_sim/launch/world_map.py)。

> **数字不许抄。** 本技能**不写**"现在有几个实体 / 覆盖多少 / 净空几米"—— 那些是随时漂移的实测值。
> 现行值一律跑核查读 JSON：`python3 tests/check_scene_geometry.py --out /tmp/geom.json`。
> 历史快照（2026-10-30 的完整演化与踩坑记录）在
> [references/MAP_DESIGN_PLAYBOOK.md](./references/MAP_DESIGN_PLAYBOOK.md)，
> **只在要追溯"为什么现在是这样"时按需加载**，不当规则用。

## 什么时候用 / 什么时候别用

- **用**：新增地图、重做布局、加障碍、改材质与配色、判断某个候选布局能不能过核查。
- **别用**：只想看现状（直接读 yaml 或跑核查）；改契约（轨迹形状 / 安全阈值 / 终态语义等）——
  那些不在本技能范围，见[硬约束](../../../docs/adr/0020-package-boundaries-and-runtime-topology.md#hard-constraints)。
  待裁定事项按 AGENTS 红线显式挂起，不静默假设。

## 不可协商的三条

1. **改地图 = 改一份 yaml。** 碰 SDF 去注入障碍就是错的。**唯一**例外是 `agc_world.sdf` 里
   **已归类为非障碍的地表模型**（如地面分层、路缘石这类薄地表—— 是**现有分类的实例**，
   不是"低矮物体一概可以放这儿"）；判据是**它是否影响车辆通行或接触**，不是高度
   —— 见 [SCHEMA-AND-DERIVATION.md](./SCHEMA-AND-DERIVATION.md#visual-vs-obstacle)。
2. **视觉与碰撞同源。** 同一段 `<geometry>` 同时注入 collision 与 visual；**禁止**装饰性无碰撞块
   （否则"看着撞了却穿过去"）。"参照物必须可碰撞，所以只能进真源"是本项目已经裁过的口径。
3. **改一次真源，立刻跑一次核查**（退出码 0 = PASS）。FAIL 就别提交、别写"应该没问题"。

## 工作循环

```text
① 先学后做 → 先查项目内同版本可运行实现，只迁移"范式"，不抄资产
② 先设计后动手 → 写只读核验器，把正式核查的口径逐项复刻，迭代候选布局到全绿
③ 再写真源 → 布局定稿后一次性写 yaml（顺序不可交换：③ 会改变 ② 的结论）
④ 正式核查 → python3 tests/check_scene_geometry.py；FAIL 先修再谈视觉
⑤ 真实取证 → 需要渲染/运行证据时，按契约与当次派工选形态；证据必须标注 backend，不得用示意图冒充
```

- **② 的产物本身就是资产**：核验器写进 `tests/` 或 `scripts/`，**不要放 `/tmp`**
  （项目历史上放过，被清理后整条判据无法复现）。
- ①②③ 的顺序不能跳：跳过 ② 直接改 yaml 是本项目返工最贵的一步。
- ⑤ 属 **T2 真实实验**（起 GUI/全链）：**未派发就不启动**，并遵守
  [EVIDENCE.md](./EVIDENCE.md) 的取证纪律与失败处理。

## 每次都要过的判断（细节见 GATES.md）

| 判断 | 现在由谁保证 | 注意 |
|---|---|---|
| schema 合法、未知值拒绝运行 | 核查 (a) + `world_map.py` 启动期守卫 | `cylinder`/`sphere` 的 `size[0]` 是**半径**不是直径 |
| 世界生成 == 真源、视觉 == 碰撞 | 核查 (b) | 另要求 `minimal` 的 `pole_*` 逐值不变 |
| 出生净空、地面激光可见性 | 核查 (g)(h) | 逐**足迹**判，不是实体中心 |
| 空中安全层存在可行解 | 核查 (i) | 待机环带半径由 `air.yaml` 的安全余量派生 |
| 覆盖率 / 多样性 / 明度带 | 核查 (o)(q) | 覆盖口径是**并集**，不是图元和 |
| **8 字轨迹净空** | **没有正式断言** | 自己在设计核验器里算；负值只说明名义轨迹压到静态圆盘，**不等于**演示必然失败，见 [GATES.md](./GATES.md) |

**闸门之间会互相踩**：加中央内容会挤掉环带，加建筑会顶爆覆盖率，分段墙反而救环带。
所以布局是**联合求解**，不是逐项满足。

## 失败处理（先看这里，别猜）

| 症状 | 第一件事 |
|---|---|
| 核查 FAIL | 读 JSON 里失败的那一项与它的子字段，按 [GATES.md](./GATES.md) 的口径复算，不要先改数字 |
| `未知 world_map=… → 拒绝运行` | 这是**设计如此**：地图清单只在 `world_map.MAP_GEOMETRY_FILES` 加一行 |
| `复合障碍 … 锚点 z 必须为 0` / `cylinder size 不相等` | 启动期守卫在拦"会静默出错"的写法，改 yaml 而不是绕守卫 |
| GUI 窗口空 / 画面是斜的 | 先查固定相机预设与 RViz 的 Fixed Frame，见 [EVIDENCE.md](./EVIDENCE.md) |
| 起 launch 立刻报环境变量不存在 | `GZ_SIM_SYSTEM_PLUGIN_PATH` 前置，见 [EVIDENCE.md](./EVIDENCE.md) |
| 内存一路涨、WSL 卡死 | 先复核配置 / 进程 / 内存与真实日志，**不要**凭症状就断定根因，见 [EVIDENCE.md](./EVIDENCE.md) |

## 边界

- **不复制约束**：坐标系、执行口、硬约束、终态语义只引用[契约真源](../../../docs/adr/0020-package-boundaries-and-runtime-topology.md#hard-constraints)；
  技能里**不转录**任何契约条文（包括轨迹形状、验收形态这类具体条款），避免出现第二规则源。
  运行时命令、后端与默认值以**当前演示入口与当次派工**为准（不确定就去读入口脚本与 launch 默认值，
  不照抄技能）。
- **不改核查口径来迁就布局**：阈值/实体上限/覆盖区间/基线例外均属验收口径，变更须交回 Leader 裁定
  并留痕，不得自己改断言让它变绿，也不得自行为某张地图开例外。
- **难以逆转的设计决定**（布局范式、schema 扩展、资产纪律）按
  [domain-modeling](../domain-modeling/SKILL.md) 的克制标准记 ADR；普通实现决定留在任务记录里。
- **因果关系要限定条件**：技能里引用的一切"实测结论"（内存、性能、环境）都只在**当时的环境与配置**下
  成立，不能当作对所有地图 / 未来环境的普遍因果；先查配置与日志，再谈根因。
