# 已结档交接任务

仅由 Codex 将 `已验收` 或有明确关闭原因的任务放入 `archive/<任务ID>/`。所有执行轮次和审查轮次随任务保留；归档后不追加实施或返工，后续工作用新任务 ID，并引用原记录。

归档步骤：

1. 在 review 中写清最终结论、结档日期和未完成项的去向；关闭不等于验收通过。
2. 确认执行会话已停止写入，将整个 `task/<任务 ID>/` 移到以任务 ID 命名的归档目录；目标目录已存在则停止，禁止覆盖。
3. 修正移动造成的相对链接和文本中的证据路径，校验链接；保留历史命令、时间、原始基线哈希和结论，不将历史基线改成当前文件值。结档后跨任务引用使用归档路径及稳定锚点，固定 `task/` 链接只用于当前接单。
4. 更新 CURRENT：发布下一任务，或设为 `空闲` 并链接最近结档记录。归档目录自身是历史列表，无需再维护一份任务状态清单。

归档包含任务 ID 下各轮次目录中的派工、回报与审查三件套；新归档使用 `archive/<任务 ID>/round-<轮次>/`，实验原始产物仍留在 `experiments/`。已有归档的历史平铺结构保持不动。本说明只管理交接记录，不改变 [项目进度真源](../../docs/archive/ROS2迁移步骤.md#status)。
