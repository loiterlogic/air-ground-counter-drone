## 3. 学习与设计依据

**来源分级**（按 [协议](#f3-changes) 的"消息来源"要求）：

| 依据 | 用法 |
|---|---|
| 用户 2026-10-31 要求（经派工单转述） | 权威目标：根因明确不该因次数返工；允许并行 |

| [P0-5 出口判据](../../../../docs/archive/completion-20261031/p0-5-协作成本治理.md#p0-5-exit) | "次数卡错维度"的实测依据；"N/K 从未被压测"→ 不能靠调参解决 |
| [P1-4 r2 报告](../../../../.coordination/archive/20261030-009-p1-4-vision/round-2/report.md#p1-4-r2-report) | 案例：T2 2/2 用满即停，两次皆自身工装缺陷 |
| [P2-1 r2 报告](../../../../.coordination/archive/20261031-011-p2-1-deliverables/round-2/report.md#p2-1-r2-report) + [其审查](../../../../.coordination/archive/20261031-011-p2-1-deliverables/round-2/review.md#p2-1-mid-review) | 案例：4/4 停工，第 4 次是无效样本重试，Leader 须单独"追认"→ 规则没写清 |

**设计原则**（三条，均从上面依据推出）：

1. **停止判据必须与成本模型同轴**：ADR-0104 说贵的是**唤醒次数**；轮数和次数都不是成本，因此不能当停止闸。→ 保留 K（无进展），去掉 N 与次数作为停止条件。
2. **失败是证据，不是结论**：协议原本区分"无效样本/有效失败"却没有对应动作；本轮把有效失败明确定义为**证据**，动作是"按根因修复重验"，不是"交回"。
3. **并行靠隔离而非靠裁决**：协议无法预见所有冲突，所以只立三条可判定的边界（文件拥有者、独占资源、CURRENT 单一写入）+ 一律先停后报，不设计"自动仲裁"。
