## 兼容性核算（先算，后跑）

三个独立边界（全部读自源码/配置，非猜测）：

| 边界 | 来源 | 值 |
|---|---|---|
| 感知量程（**三维**） | `air_perception.cpp:358-366` `r=‖target−uav‖`；`range_max_m=12.0` | 水平预算 = √(12²−0.5²) = **11.990 m**（dz = 2.5 巡航 − 2.0 目标） |
| 安全层目标圆盘 | `safety_shield.cpp` `target_min_dist + target_margin + dynamicMargin` | 8.0 + 1.5 + (0.2×2.0 + 0.3) = **10.200 m** |
| 站距带语义 | `standoff_follower.cpp:147-160` | `r>safe_max ⇒ 收敛到 safe_max`；`r∈[safe_min,safe_max] ⇒ 原地保持` |

⇒ 可行窗口 **(10.200, 11.990)**，宽 **1.79 m**。`safe_max=11` 落在窗口内
（距量程 +0.99 m，距安全圆盘 +0.80 m）。**但窗口本身很窄**——"11 够不够"取决于实测跟踪滞后
是否吃掉了这 1 m 余量，只能由干预证据回答。
