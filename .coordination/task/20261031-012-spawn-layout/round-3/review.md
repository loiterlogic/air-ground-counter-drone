# F1 round-3 独立验收

来源：Leader，2026-10-31。亲读 round-3 报告、air.yaml 差异、量程/跟踪源码与实验台账；独立复跑 `w6_geometry_check.py` 与 `./run_demo.sh test`。

结论：**F1 已验收，附已知边界**。

## 验收结果

- 出生布局真源与生效链通过：车 `(-15,1)`、目标 `(15,-2)`、己方机 `(-11,1)`；世界 spawn、复位和己方机起飞参考有逐位日志证据。
- 三组设计距离、C7、三图派生链与启动断言通过；非有限值守卫、own pose 生效值、goal 派生/场景覆盖、r014 边界输入修正均有离线证据。
- H3 配置冲突通过最小干预确认：`safe_max 15→11` 后 visibility `0.228→0.900/0.931`、最长失联 `28.8→3.5 s`、hold `3→0`；三维量程水平预算 11.990、目标安全圆盘 10.200，11.0 在实测兼容窗口内。写真源只改 safe_max，未改量程、安全余量、C1/C10 或 ABI。
- 默认 `full+yard+s04+seed0+GUI` 连续三次成功记录，C9 为 0；完整冒烟 5/5 通过。Leader 独立命令复跑几何核查与冒烟均 exit 0。
- 失败样本保留：默认验证中的 PX4 `blind land` 失败及 infra 失败均未计入成功，H2 CPU 争抢尚未通过独占对照证明，不包装成布局成功率或稳定性统计。

## 已知边界

- 精确终态瞬间截图未取得：默认配置有出生帧和末期帧，末期帧明确不是终态帧；不以它冒充终态证据。已存在的 round-2 精确终态帧属于旧 safe_max=15 配置，不能替代新配置的终态帧。
- F1 证明的是本机、本场景、本 seed 的有限复现与配置兼容，不证明跨机器、跨 seed 或统计稳定性。
- round-1 `/dev/shm` 批量删除越界与证据缺口按历史记录保留；round-2/3 零共享内存写删。`safe_max` 变更有 ADR/参数真源依据，但完整参数标定仍属后续工作。
