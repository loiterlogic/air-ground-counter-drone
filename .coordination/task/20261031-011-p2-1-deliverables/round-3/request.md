```python
gray_band = np.abs(rgb.astype(int) - 218).max(axis=2) < 4   # 逐像素是否"平灰 218"
row_frac  = gray_band.mean(axis=1)                          # 每行的命中占比
# 从第 0 行起，连续满足 row_frac > 0.9 的行数 ÷ 图像高度
```

| 取值 | 判定 |
|---|---|
| **≤ 0.10** | **俯视成立** |
