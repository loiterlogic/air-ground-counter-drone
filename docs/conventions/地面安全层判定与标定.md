> 本文件是**工程规范**：把 [ADR-0045](../adr/0045-ground-safety-layer-self-owned.md#top)
> 的决策落成可复核的判定表、标定步骤与整链验收矩阵。
>
> 约束类信息（唯一执行口、坐标系、消息 ABI、参数入口）**只引用**

| 类别 | 现状 | 能否进代码默认值 |
|---|---|---|
| 三档距离 `d_emergency/d_collision/d_safety`（1.0 / 2.0 / 4.0 m） | **沿用 [ADR-0010](../adr/0010-safety-thresholds-and-failsafe.md#top) 的实测回填值** | 能（已是现行口径）|

## 1. 状态机与不变量

<a id="state-set"></a>

### 1.1 状态枚举（唯一真源在此，代码常数须与本表逐项一致）

| 状态 | 含义 | 输出 | 可自动恢复 |
|---|---|---|---|
| `STARTUP` | 节点已运行但尚未收到任何必需输入 | 零速 | 是 |
| `NO_COMMAND` | 原始速度意图从未收到，或已超过命令超时 | 零速 | 是 |
| `NO_PERMIT` | `/agc/task/state` 不是在驱动许可状态内，或许可本身过期 | 零速 | 是 |
| `BODY_INVALID` | `/agc/ground/odom` 缺失 / 超龄 / 负年龄 / `odom_valid=false` / 四元数非法 | 零速 | 是 |
| `MAP_MISSING` | 从未收到过 `/agc/map` | 零速 | 是 |
| `MAP_STALE` | 地图年龄超过地图超时 | 零速 | 是 |
| `MAP_INVALID` | `/agc/map/valid=false`，或地图几何/坐标系不一致（见 §2.2） | 零速 | 是 |
| `CLOCK_ANOMALY` | 任一输入 `stamp` 在本地时钟的未来（`age < 0`） | 零速 | 是 |
| `PARAM_INVALID` | 启动期参数校验失败（顺序不变量被违反、必填缺失、取值非有限） | 零速（并**拒绝启动**） | 否 |
| `BUDGET_EXCEEDED` | 单拍判定超时 / 扫掠格数超上限 | 零速 | 是 |
| `STOP_EMERGENCY` | footprint 已与阻挡格相交，或 `d < d_emergency` | 零速 | 是（带迟滞） |
| `STOP_COLLISION` | `d_emergency ≤ d < d_collision` | 零速 | 是（带迟滞） |
| `SLOW` | `d_collision ≤ d < d_safety`，或扫掠区内含 `1–98` | 裁剪后的速度 | 是 |
| `PASS` | `d ≥ d_safety` 且扫掠区全为已知自由 | 原命令（限幅后） | — |

<a id="invariants"></a>

### 1.2 不变量（任一被违反即 `PARAM_INVALID` 并拒绝启动）

1. `0 < d_emergency < d_collision < d_safety`（顺序沿用
   [ADR-0010](../adr/0010-safety-thresholds-and-failsafe.md#top) 的档位顺序不变量）。
2. `d_recover_pass > d_safety` 且 `d_recover_slow > d_collision`（**恢复门槛严格高于进入门槛**，
   否则会在门槛上抖动）。
3. `t_map_timeout ≥ 3 × 地图发布周期`、`t_body_timeout ≥ 3 × 车体状态发布周期`、
   `t_cmd_timeout ≥ 3 × 命令源发布周期`、`t_permit_timeout ≥ 3 × 任务状态发布周期`。
4. `v_cap ≤ 车体模型上限`、`ω_cap ≤ 车体模型上限`（与 `agc_sim/config/car.yaml` 同源）。
5. `budget_ms > 0`，`sweep_cell_limit > 0`。
6. 所有阈值有限（非 NaN / 非 ±Inf）。

<a id="order"></a>

### 1.3 判定顺序（**不可交换**）

```
① 参数闸（启动期一次；非法即拒绝启动）
② 时钟闸：任一 stamp 在未来 → CLOCK_ANOMALY
③ 输入存在性闸：无命令 / 无地图 / 无车体 / 无许可 → 对应状态
④ 输入时效闸：超时 → 对应状态
⑤ 一致性闸：地图几何 / 坐标系 / odom_valid → MAP_INVALID / BODY_INVALID
⑥ 许可闸：任务状态不在许可集合 → NO_PERMIT
⑦ 可停性闸：footprint 扫掠 → 阻挡 / 未知 / 未知占比
⑧ 定档：PASS / SLOW / STOP_COLLISION / STOP_EMERGENCY（含迟滞）
⑨ 裁剪与发布
```

**为什么顺序不可交换**：早退到 `NO_COMMAND` 之前若先算扫掠，会在地图缺失时把
"没有地图"误报成"前方未知"——两者调参方向相反（补链路 vs 补感知）。
同理，许可闸必须晚于一致性闸：`/agc/task/state` 本身就可能是"地图不可用"的后果，
先报 `NO_PERMIT` 会掩盖真正的失效源。

<a id="directional"></a>

### 2.0 定档量：**方向化走廊净空** `d_corridor`（ADR-0047）

改造前定档用 `d_min_m`（车体外缘到**任意方向**最近阻挡格）。那是**各向同性圆形禁行区**：
侧面 2 m 外的柱子，即使车笔直沿走廊走、永远不会碰到它，也判 `STOP_COLLISION`。
实测后果（`dense_map`，面积覆盖仅 7.2%、车宽 0.57 m）：出生点一启动即零速，整链 0/20 到达。

**现行口径**（ADR-0047）：

| 量 | 定义 | 参与定档 |
|---|---|---|
| `d_min_m` | 车体外缘到**任意方向**最近阻挡/未知格 | **否**（只作诊断） |
| `d_corridor_m` | **沿当前运动方向**、车体宽度带内（`|横向偏移| ≤ half_width + cell_epsilon`）的纵向间隙 | **是** |

- `d_corridor_m < 0` = 走廊带内**无阻挡** ⇒ 前方净空**无穷**，三个距离档（emergency / collision /
  slow）**一律不成立**。**不得**在此退化去用 `d_min_m`（那等于变更没做）。
- **侧方障碍只经扫掠生效**：`swept_blocked` 沿实际制动轨迹扫掠（含 `ω` 引起的偏航变化），
  "当前转向会不会扫到侧方"由它覆盖，**不**由距离档额外判一次。
- **原地旋转**（`v≈0 ∧ w≠0`）：距离档退化为各向同性，但**只用于限速**，不判停车。
- **静止**（`v≈0 ∧ w≈0`）：无运动方向，退化为各向同性判据（保持既有判定表）。

判定表第 6 / 9 / 10 / 24 / 25 例里的 `d` 现指 `d_corridor`；第 2 / 12 / 22 例不受影响
（走扫掠与 footprint 相交）。

<a id="edge"></a>

### 2.1 「仅边缘相交」的边界口径

栅格判定天然有半个格子的量化误差。口径定为：**扫掠区按车体 footprint 的真实闭包
（不是格中心）膨胀 `cell_epsilon`** 后取格；判碰撞用**格中心是否落在膨胀闭包内**。

- 这样"擦边"是**判碰撞**（保守方向），而不是"不判"；
- 因此用例 8 的"仅边缘相交"指的是：阻挡格只与**未膨胀**的扫掠闭包相切、
  且其格中心落在膨胀闭包之外——即量化意义上的"贴着但不进"。
- `cell_epsilon` 与格分辨率、footprint 离散误差一起标定（§3.5），不得取 0。

<a id="consistency"></a>

### 2.2 「一致性闸」检查什么

| 检查 | 判据 | 不通过 |
|---|---|---|
| 地图坐标系 | `header.frame_id == world` | `MAP_INVALID` |
| 命令坐标系 | `header.frame_id == car/base_link` | `INVALID`（`frame mismatch`） |
| 地图几何 | `resolution > 0`、`width/height > 0`、`data.size() == width*height`、原点有限 | `MAP_INVALID` |
| 地图与车体同域 | 车体 `(x,y)` 落在地图矩形内 | 落在外 ⇒ 该点按 **unknown** 处理（不是"自由"） |
| 车体有效性 | `odom_valid == true`、四元数有限且单位范数、协方差有限 | `BODY_INVALID` |
| 命令有效性 | 六分量有限、差速车 `|linear.y| ≤ eps`（非完整约束） | `INVALID` |

## 3. 标定方案（真实差速车、可重放）

<a id="calib-order"></a>

### 3.1 顺序（前一步的输出是后一步的输入，不得乱序）

```
① 动力学：v_max / ω_max / a_brake（锁轮制动） 
② 反应窗口：T_react（链路 + 判定 + 执行延迟的实测上界）
③ 制动距离：s_brake(v) = v·T_react + v²/(2a_brake)
④ 时间窗口：t_cmd / t_body / t_map / t_permit（各 ≥3× 发布周期，且满足总停距约束）
⑤ 距离档：d_emergency / d_collision / d_safety
⑥ 迟滞：N / d_recover_pass / d_recover_slow
⑦ 离散误差：cell_epsilon / footprint 覆盖误差（对真实接触真值）
⑧ 预算：budget_ms / sweep_cell_limit
⑨ 逃逸能力：slow_min_ratio 的**物理下限**（不是手感值）
```

**⑨ 为什么必须单列**（2026-11-13 实测发现）：`SLOW` 把 `v` 与 `ω` **同比例**裁剪，
横移 ≈ `(v/ω)(1−cos ωT)` —— 比值不变，但 `ω` 变小让 `(1−cos ωT)` **变小**，净效果不显然。
实测 `slow_min_ratio = 0.2` 时 2 s 横移只有 **0.0002 / 0.030 / 0.048 m**（车基本不动），
即"裁得越狠，越不会躲"。故下限由 `slowRatioFloor()` 从
`lateral_reach_required_m / lateral_window_s / lateral_eff_ratio` 反解，
**低于下限拒绝启动**。这条不会体现在任何停车判据里，只会在真正需要躲开时暴露。

**能力主张与实测的当前值**（[ADR-0046](../adr/0046-lateral-escape-capability-narrowing.md#top) 裁定）：

| 量 | 现行值 | 来源 / 口径 |
|---|---|---|
| `max_offset` = `lateral_reach_required_m` | **0.65 m** | 方法修正后 6 轮实测 `0.6888–0.8769 m`，取在下沿之下留 5.6% 余量；**三处必须同值**（`rl.yaml` / `ground.yaml` / `safety_policy.hpp`），闸门见 `tests/check_safety_lateral_consistency.py` |
| `lateral_window_s`（反应窗口 `T`） | **2.0 s** | ADR-0010 口径，**不**为迁就能力主张而放宽 |
| `lateral_eff_ratio`（实测折扣） | **0.55** | 同轮理想圆弧 1.398 m 对实测最小 0.6888 m（折扣 0.4927，取 0.55 略宽松但仍保守） |
| `slow_min_ratio`（终值） | **1.0** | `slowRatioFloor()` 按 `eff=0.55` 反解 0.5461，但按**最坏折扣 0.4927** 反解 `need=1.319 > L(1)=1.2402` ⇒ 满速都不够，故取 1.0（不降速）|

⇒ **`SLOW` 档事实上不降速**。这是诚实结论而非缺陷：本车能力**贴着**要求，
任何降速都会让"能躲开"退化成"躲不开"。**代价**：安全带内没有减速缓冲，
该风险由三档距离（4.0 / 2.0 / 1.0 m）承担，**不得**再声称"安全带内会减速"。

### 3.1.1 横向逃逸的**测量口径**（三条，缺一即量错）

2026-11-13 实测踩过两次，都是"量错了尺子"而不是"车不行"：

1. **横移取「垂直于初始航向的位移投影」，不是世界 `y` 差值**。
   只有初始 yaw≈0 时两者才相等。本仓把车摆成**朝 +y**（yaw=π/2），横向 = 世界 **x** 位移；
   取 `y` 差值会把"沿车头方向的前进"算成横向（实测 1.4 m 的前进被读成 0.1 m）。
2. **起点必须在命令发出**之前**取**。原地打角时车先转不前进，
   把起点取在转矩段之后会丢掉一部分真实横移。
3. **SLOW 起点必须用「静止 `d_min_m` + 实际命令后的档位」双判据确定**，
   不能按"障碍在 N 格外"估算，也**不能只看静止时的 `d_min_m`**。
   两次实测各踩一次：
   - 按格数估（6–13 格）在 `yard` 的**膨胀地图**上等于 3–6.5 m ⇒ 落到 `STOP_COLLISION`；
   - 只看静止 `d_min=3.39 m`（看似在 `SLOW` 带内）⇒ 一旦给上 `v=1.0` 的**制动扫掠**，
     同一位置直接落进 `STOP_EMERGENCY`、`v_out=0`、车位移 `0.000`。
     **而 trace 里记的 `tier` 是"加速段之后"的残留值，看起来像 `SLOW`，实际根本没在
     `SLOW` 下动过** —— 这是最容易被误读成"SLOW 让车不会动"的形态。

   正确做法：候选点逐个试摆 → 读静止 `d_min_m` 落在 `(d_collision+0.2, d_safety−0.2)`
   → **再用与正式测量相同的命令跑 1 s**，确认 `state == SLOW` 且 `v_out > 0`
   → 两者都满足才采用。判据来自**生产判定**本身，换地图 / 换分辨率都不用改这里。

   **独立佐证**（受控探针，同一次整链里前后对照）：

   | 位置 | 命令 | 安全层状态 | `v_out` | 车实测位移 |
   |---|---|---|---|---|
   | `(-4.78, -20.38)`（`jersey_row` 旁 2.36 m） | `v=1.0, w=0` | `STOP_EMERGENCY` | 0 | **0.0000 m** |
   | `(-17.90, 3.80)`（开阔区） | `v=1.0, w=0` | `PASS` | 1.0 | **1.7169 m** |

   这张表同时证明了两件事：安全层**确实**在挡（不是车坏了），
   以及"车不动"完全可以由**摆错位置**造成。

**可重放**：每轮逐拍真值轨迹落 `escape_arc_traces.json`，由
[`tests/replay_escape_trace.py`](../../tests/replay_escape_trace.py) 离线重算横向位移与折扣。
"最小值 / 折扣 / 失败样本"因此变成**别人能自己重算的量**，而不是只能相信标定那一刻的结论。

**为什么动力学必须先于档位**：三档距离全部由 `s_brake` 与 `T_react` 推出；
先定档位再补动力学等于"先给答案再找依据"。

### 3.2 必须记录的数据字段（缺一即判定标定无效）

| 字段 | 含义 | 来源 |
|---|---|---|
| `run_id` / `git_commit` / `params_hash` | 可复现身份 | 实验产物 |
| `v_cmd_raw` / `v_cmd_safe` / `ω_cmd_raw` / `ω_cmd_safe` | 原始与有效速度（同拍配对） | 安全层 |
| `v_truth` / `x` / `y` / `yaw` | 车体真值 | `/agc/ground/odom` |
| `sweep_cells` / `budget_used_ms` | 计算量 | 安全层诊断 |
| `d_min_m` / `d_min_cell` | 本拍**各向同性**最小净空与其格 | 安全层诊断（**不参与定档**） |
| `d_corridor_m` / `d_corridor_cell` | 本拍**方向化走廊**净空与其格（`<0` = 带内无阻挡） | 安全层诊断（**定档用**） |
| `map_age_s` / `cmd_age_s` / `body_age_s` / `permit_age_s` | 四类输入年龄 | 安全层诊断 |
| `unknown_ratio_swept` | 扫掠区未知占比 | 安全层诊断 |
| `tier` / `reason` | 档位与原因 | 安全层诊断 |
| `gz_contact` | 是否发生真实物理接触（接触对） | GZ 接触传感器 |
| `stop_distance_m` | 从触发到真值停稳的位移 | 由真值与 `tier` 上升沿算 |

<a id="replay"></a>

**可重放**（**已落地**）：标定必须能以**录制的输入序列**（命令 + 地图快照 + 车体状态 + 任务状态）
离线重跑判定类，且**逐拍输出与在线一致**。做不到就不是标定，是"这一次看起来没事"。

链路与用法：

```bash
# 1) 录制（需 backend:=full；按 safety_status 心跳对齐采样，地图按内容去重）
python3 tests/record_safety_inputs.py --out /tmp/safety_trace.jsonl --duration 60
# 2) 离线重放 + 逐拍对拍（不需要 ROS / 仿真；调用**生产类** SafetyPolicy）
./build/agc_ground/safety_replay /tmp/safety_trace.jsonl
```

**口径纪律**（三条，缺一即对拍失真，均已实测踩过）：

1. **`now_s` 必须与输入 stamp 同一时基**：用系统时钟而消息 stamp 是仿真时间 ⇒ 年龄算成 1.79e9
   ⇒ 全部假 `MAP_STALE`。
2. **`now_s = max(各已收到输入的 stamp)`**：地图 2 Hz、任务 1 Hz，其 stamp 可能**超前**同拍命令
   （实测 0.26 s）⇒ 只锚命令会判 `CLOCK_ANOMALY`，而线上 `now()` 恒 ≥ 已收到的任何 stamp。
3. **年龄是输入，原样回喂**：不要用"消息 stamp + 自算 now"重新推年龄，否则会混入一次采样相位误差，
   对拍变成"两种算法互相比"。录制端存下在线算好的四个年龄，重放端反解 stamp。

**一致性边界**：重放复现**判定**，不复现 QoS / 发现 / 时钟同步，也不复现节点里
`budget_ms` 的在线实测耗时。

<a id="calib-targets"></a>

### 3.3 标定要回答的问题（不是"填几个数"）

1. **最大安全速度**：在 `d_safety` 内出现阻挡时，多大 `v` 仍能停住？
   ⇒ 给出 `v_safe(d)` 曲线的实测拟合，不是单一常数。
2. **横向逃逸能力**：本车实测横向约 `1.0 m / 2.0 s`（理想圆弧的 ~0.72×）。
   ⇒ `SLOW` 的 `ω` 上限必须与该能力一致，**不得**用理想圆弧推定。
3. **地图分辨率与 footprint 的离散误差**：对同一组真实接触事件，
   `cell_epsilon` 取多大才既不过度保守（永久 `SLOW`）又不漏报？
4. **端到端延迟**：命令发布 → 判定 → 发布 → 中继 → 物理响应的 p50/p95；
   `T_react` 取 p95 而非均值。
5. **未知占比阈值的实际分布**：正常行驶时扫掠区 unknown 占比的分布；
   阈值不得落在分布中位数附近（否则一半时间在停车）。

<a id="calib-gate"></a>

### 3.4 标定完成判据

- 每一条 §3.2 字段在产物中有值（`null` 必须有 `not_applicable` 说明，不得以 0 冒充）；
- §3.3 的五个问题各有**实测数字 + 出处**；
- 「录制的输入序列离线重跑」与在线逐拍一致（逐拍 diff 为空）——
  **2026-11-13 实测：974 拍，一致 974，不一致 0**；
- 重标定触发器写清：换底盘 / 换摩擦面 / 换地图分辨率 / 改变 footprint ⇒ 全部重标。

<a id="calib-discrete"></a>

### 3.5 离散误差的标定方法

对每个真实接触事件，比较三种判据的判定时刻：
① 连续几何（离线精确解，作为参照）；② 本层栅格判定；③ GZ 接触真值。
统计 ②−① 与 ②−③ 的偏差分布，取 `cell_epsilon` 使 ② 在 **②−① ≥ 0**（保守）前提下
尽量小。**不得**为让指标好看而取 0。

## 4. 整链验收矩阵

<a id="layers"></a>

### 4.1 三层递进（先逻辑、再规模、最后 GUI 取证）

| 层 | 环境 | 能证明什么 | **不能**证明什么 |
|---|---|---|---|
| L-逻辑台架 | 无 ROS、无仿真，喂录制的输入序列 | 判定表 25 例逐条成立、状态机与迟滞正确、诊断字段齐全 | 真实动力学安全、时序、可见性 |
| L-规模 | headless 整链（`full` backend，`dense_map`） | 长时间不崩、预算与帧率达标、无第二命令者、失源即停 | GUI 可见性与人工判读 |
| L-GUI | GUI 整链（关键场景） | 障碍前限速/停车可**看见**、恢复不误放行 | 规模统计 |

**顺序不可颠倒**：L-逻辑台架通过后才能进 L-规模；L-规模结果**不得**当作动力学安全证据。

<a id="matrix"></a>

### 4.2 矩阵（每格给出判据与证据字段）

| # | 场景 | 期望 | 判据（可判定） | 证据字段 |
|---|---|---|---|---|
| A1 | 正常放行 | 无阻挡直行 | `tier == PASS` 占比 ≥ 0.95，`v_cmd_safe == v_cmd_raw`（除限幅） | `tier` 序列 |
| A2 | 障碍前限速 | 车前障碍在 `d_safety` 内 | 先出现 `SLOW` 且 `v_cmd_safe < v_cmd_raw` | `tier` / 速度对 |
| A3 | 障碍前停车 | 继续逼近 | 出现 `STOP_COLLISION`；`stop_distance_m ≤ d_collision`**上界**内真值停稳 | `stop_distance_m` |
| A4 | 急停 | 障碍突现于 footprint 内 | `STOP_EMERGENCY`，**无** `gz_contact` 计数 | `gz_contact == 0` |
| B1 | 地图失源 | SIGSTOP `map_adapter` | 地图年龄超时后 `MAP_STALE`，真值在"盲行+制动"上界内停住 | `map_age_s` / 位移 |
| B2 | 命令失源 | 命令源停发 | `NO_COMMAND`，零速 | `cmd_age_s` |
| B3 | 车体失源 | SIGSTOP `ground_odom_adapter` | `BODY_INVALID`，零速 | `body_age_s` |
| B4 | 许可撤销 | 任务 abort | `NO_PERMIT`，零速 | `tier` |
| B5 | 地图无效 | 强制 `/agc/map/valid=false` | `MAP_INVALID`，零速 | `valid` 序列 |
| C1 | 启动无命令 | 链路起但命令源从未发 | **每一拍都有** `cmd_vel`（零速），无空窗 | 发布计数 vs 周期 |
| C2 | 恢复不误放行 | 障碍移除 | `STOP*` 至少持续 `N` 拍，之后才 `PASS` | `tier` 序列 + 拍数 |
| C3 | 唯一执行口 | 全场景 | `/agc/ground/cmd_vel` 发布者数 `== 1`；`/model/agc_car/cmd_vel` ROS 侧 `== 1` 且为 `ground_drive_relay` | `ros2 topic info -v` |
| C4 | 预算 | 规模层长跑 | `budget_used_ms` p99 ≤ `budget_ms`；无 `BUDGET_EXCEEDED` 误触发 | 预算直方图 |
| D1 | 接触真值关系 | 全部停车场景 | 版本化记录：本层 `tier` 序列 ↔ GZ 接触真值（`gz_contact` 计数与时刻） | 对拍表 |

<a id="evidence"></a>

### 4.3 证据登记要求

- 每格产物必须含 `params_hash` + `git_commit`，否则不可复核。
- **A4 / A3 必须成对出现**：只有"停住了"而没有"本来会撞"的对照，不构成安全证据。
- **B 组四类失源各自独立取证**：用"命令源停了所以安全层没输出"冒充"地图失源即停"是错误归因。
- **C1 必须按拍统计**，不能用"终端上有零速打印"当证据。

<a id="version"></a>

### 4.4 指标口径版本化

| 指标 | 旧口径 | 新口径 |
|---|---|---|
| `shield_infeasible_rate` | 触发拍代理（Nav2 `action_type` + GZ 接触） | 本层 `tier` 上升沿 + GZ 接触真值 |
| `trigger_events` | Nav2 `STOP/SLOWDOWN` 上升沿 | 本层 `STOP_*` / `SLOW` 上升沿 |

## 5. 任务1 地图可消费性的前置核查（已落地）

安全层只能消费**已被验证**的地图表示。以下为**可复核事实**，不是承诺：

| 项 | 事实 | 出处 |
|---|---|---|
| 规划层消息 | `nav_msgs/OccupancyGrid`，`/agc/map`，`frame_id=world`，值域 `-1/0/1–98/99/100` | `map_adapter.cpp` / [ADR-0041](../adr/0041-geometry-metadata-instances-and-risk-map.md#top) |
| 逐格元数据 | `agc_msgs/PerceptionCellMeta`，`/agc/map/cell_meta`，并行数组长度 `== width*height` | 同 ADR；`publishCellMeta()` |
| 坐标系 / 时间戳 | 均由 `map_adapter` 打 `world` + 本地时钟；地图拍按 `rate_hz=2.0` | `publishMap()` |
| QoS | 地图与 `valid` / `version_hash` / `update_seq` 均 **transient_local + reliable** | `map_adapter.cpp` 的 `latched` |
| unknown 语义 | `-1` 与 `1–98` 都**不是已知自由**；`>=100` 才是阻挡 | [ADR-0041](../adr/0041-geometry-metadata-instances-and-risk-map.md#top) + `planning_policy.hpp` |
| 地图新鲜度 | `/agc/map/valid` = `geometry_ok && (now - last_source) ≤ source_max_age_s`（默认 1.0 s） | `knowledge_current()` |
| 无平行表示 | 安全层订阅集合**不含** `scan` / 点云 / costmap | [ADR-0045](../adr/0045-ground-safety-layer-self-owned.md#inputs) |

**已实施的交付物**：`ground_safety_filter`（节点）+ `safety_policy.hpp`（纯判定类）+
`test_safety_policy.cpp`（45 条 gtest）。节点级三档与启动零速已有实跑证据，
见 [ADR-0045 的实施回填](../adr/0045-ground-safety-layer-self-owned.md#top)。

**如实登记的能力缺口（不得据此宣称安全层已达标）**：

- `dense_map` 的感知六项判据**仍有 3 项未通过**（误覆盖率、IoU、稳定性 p99），
  见根 README 已知边界。安全层建在**未完全达标**的地图上 ⇒ 其误报/漏报率继承该缺口。
- 地图**不覆盖细杆**（`< 0.24 m`），而 Nav2 `scan` 曾能看到 —— 这是能力退化，已登记。
- 地图**无动态障碍层**，移动障碍不在保证范围。
- 证据层（0.25 m）与规划层（0.5 m）之间是 **max-pool 保守派生**，
  安全层用的是保守化后的结果：小障碍会被放大到整格。这是安全方向的，但会提高误停率。
- **不含空中链路的台架没有障碍输入**：`safety_scenario`（及任何只起 `skeleton` 的栈）
  没有 nadir 相机 ⇒ 地图恒空 ⇒ 新层严格 fail-closed 只能停。这是**输入契约的必然结果**，
  不是缺陷；补地图来源属后续任务（详见 ADR-0045 的实施回填）。
