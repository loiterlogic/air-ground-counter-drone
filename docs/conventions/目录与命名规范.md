# 目录与命名规范

> 本文件是 W0 产出的**工程规范**，约束后续所有 workstream 的命名与目录。
> 约束类信息（坐标系、唯一执行口、参数入口、硬约束）**只引用**契约真源 [ROS2迁移交接文档](../ROS2迁移交接文档.md)，本文件不复述。

## 1. 顶层目录骨架

```
AGC/
├── AGENTS.md                                    # 唯一入口索引（L1 必读）
├── GLOSSARY.md                                  # 术语
├── .agents/                                     # 项目级 Agent 资产（技能，入库）
│   ├── README.md
│   └── skills/<name>/SKILL.md
├── .coordination/                               # Leader / Worker 交接（入库）
├── docs/
│   ├── ROS2迁移交接文档.md                       # 契约真源（唯一约束来源）
│   ├── plan/                                    # 当前方向：项目收尾路线（P0→P2）
│   ├── adr/                                     # 决策记录 + 自动索引 README.md
│   ├── conventions/                             # 工程规范（本目录）
│   ├── reviews/                                 # 评审快照（结论来源证据）
│   ├── toolchain/                               # 工具链说明文档
│   ├── archive/                                 # 历史（Runbook / ROS1 基线 / 规格）
│   │   └── specs/<ws>/{spec,tasks,checklist}.md  # 历史规格（本机保留，不发布）
│   └── temp/                                    # 过程草稿（忽略）
├── src/                                         # ROS2 包（colcon 源）
├── experiments/                                 # 实验产物（唯一落点）
├── scripts/                                     # 长期工具（+ research/ 暂停未废弃、archive/ 一次性驱动）
├── tests/                                       # 验收/回归核查（退出码语义）
├── reference/                                   # 归档旧树（2026-10-31 退役删除，ADR-0025）
├── toolchain/                                   # 外部仓库 / 工具链（不入库，仅 README）
└── build/ install/ log/                         # colcon 产物（忽略）
```

## 2. 包名

- 本项目自有包统一 `agc_<域>`，全小写、下划线分隔。
- 第三方包原样置于 `src/`，**不改造、不改名**（如 `px4_msgs`）。

## 3. 话题

- 协同层统一命名空间 `/agc/`，形如 `/agc/<域>/<对象>`。
- 既定名以契约真源为准：参数入口见 [参数入口](../ROS2迁移交接文档.md#params)，唯一执行口见 [唯一执行口](../ROS2迁移交接文档.md#execution-port)。

## 4. TF 帧

- 机体系一律 `<实体>/<link>`（如 `drone/base_link`、`car/base_link`），**禁止裸 `base_link`**。
- 依据契约 [命名空间与坐标系](../ROS2迁移交接文档.md#namespace)。

## 5. 参数

- 形如 `/agc/<域>/<名>`，由 launch **单一设置**，节点**不得覆写**。
- 参数入口清单见契约 [参数入口](../ROS2迁移交接文档.md#params)。

## 6. 文件命名

- **源码与配置文件**一律 `snake_case`（如 `task_manager.cpp`、`scenario_params.yaml`）。
- **文档**（`docs/**`、`*.md`）不受此限，沿用中文标题文件名（与既有真源一致）。
- 禁止在文档路径中使用空格。

## 7. 分支

- 每个 workstream 一个分支：`ws/<id>-<slug>`（如 `ws/w0-conventions`）。
- 验收通过后合并回 `main`。

## 8. spec 目录

- **历史规格**：迁移期每个 workstream 的规格（三件套 `spec.md` / `tasks.md` / `checklist.md`）已于 **2026-11-03 删除**——其决策结论已被 ADR 吸收、验收判据已固化成 `tests/` 里的可执行核查（[ADR-0025](../adr/0025-publishing-boundary-and-retirement.md#top)）。
- **任务文件**：按 [任务计划规则](../plan/README.md#plan-index) 在 `docs/plan/` 临时立项，**结档即删**；结论必须先进永久归宿（ADR / `docs/conventions/` / 契约），不得长期引用。
- 新建规格前先确认是否真的需要：**决策**归 ADR、**验收判据**归 `tests/`，两者都放不下的才需要新规格。

## 9. 构建系统

| 包类型 | 构建系统 |
|---|---|
| C++ 节点包 | `ament_cmake` |
| 接口包（消息 / 服务 / action） | `ament_cmake` + `rosidl_default_generators` |
| Python 包（RL / 工具） | `ament_python` |

各包职责与依赖方向见 [包边界](包边界.md)。

## 10. 产物分类与生命周期

每类信息**只有一个家**；新增任何产物前先确认它属于哪一类、落在哪个家。

| 产物 | 家 | 生命周期 |
|---|---|---|
| 长期工具（跑批 / 归档 / 审计 / 校验） | `scripts/` | 常驻、入库；见 [scripts/README](../../scripts/README.md) |
| 研究期工具（暂停但未废弃、仍可复跑） | `scripts/research/` | 不删除；见 [research/README](../../scripts/research/README.md#research) |
| 一次性驱动 / 台架 / 探针（按风险项产出） | `scripts/archive/` | 证据归档后不再改动，保留供复核 |
| 验收 / 回归核查（断言行为、**退出码语义** 0=PASS） | `tests/` | 常驻、入库；见 [tests/README](../../tests/README.md) |
| **退役物**（已停用功能的代码 / 配置 / 参数 / 场景轴） | 无独立目录：删除或移 `scripts/archive/` / `docs/archive/` | **不留活跃层**；唯一清单是[路线分支治理 5.2 台账](路线分支治理.md#current)，逐项配防复活闸门；「保留但固定值 / 保留但登记」按该规范 4.4 / 4.5 执行 |
| 架构 / 契约级决策 | `docs/adr/` | 入库、只追加、不重写历史 |
| 窄实现决定（只约束一次修复） | 对应 `tests/` 核查 + ADR 的「实施回填」节 | **不**升独立 ADR |
| 项目级可复用 Agent 技能 | `.agents/skills/<name>/SKILL.md` | 入库；Harness 默认扫描根（[ADR-0025](../adr/0025-publishing-boundary-and-retirement.md#top)） |
| 历史文档（Runbook / 旧系统盘点） | `docs/archive/` | 只读查阅；不重写结论，只允许修路径与导航 |
| 评审快照及其结论来源证据 | `docs/reviews/` | 入库；如 `agc-review-<date>/` |
| 过程草稿 | `docs/temp/` | **忽略**，可随时丢弃 |
| 实验产物 | `experiments/` | 唯一落点（ADR-0006）；大归档见 ADR-0006 |

- **ADR 分两级**：只有**会约束未来工作**的架构/契约决策进 `docs/adr/`；一次性的实现决定留在对应任务的记录与 `tests/` 核查里。
- **`docs/temp/` 与 `docs/reviews/` 不混用**：临时物与结论证据分属两个家。
