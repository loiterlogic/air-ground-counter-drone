# 地面横向逃逸能力裁定：收窄 `max_offset`、冻结反应窗口、`SLOW` 不降速

## Status

accepted（2026-11-13，用户裁定；收窄能力主张，**不改**反应窗口与安全层判据结构）

> **取代范围（部分 supersede）**：[ADR-0004](0004-ground-control-rl-primary-and-nav2-safety.md#top)
> (e) 的**能力主张部分** —— `max_offset = 1.0 m` 这个数值及其"2 s 内横移 1 m 可达"的表述。
> **仍有效的部分**：动作方向约定 (c)、净空量纲 (d)、`min_offset = 0.3 m`、
> 「不得用理想圆弧推定横向能力」的方法论、(e) 的**测量口径**（反应窗口 `T = 2.0 s`）。
>
> **不取代**：[ADR-0010](0010-safety-thresholds-and-failsafe.md#top) 的档位顺序不变量与三档绝对值；
> [ADR-0045](0045-ground-safety-layer-self-owned.md#top) 的输入契约、判定模型与失效语义。

## 背景

三份文档各自成立，合起来却互相矛盾：

| 来源 | 主张 |
|---|---|
| [ADR-0004](0004-ground-control-rl-primary-and-nav2-safety.md#top) (e) | `max_offset = 1.0 m`：4 次采样 `1.043 / 1.287 / 1.083 / 1.017 m`，**均 ≥ 1.0** |
| [ADR-0010](0010-safety-thresholds-and-failsafe.md#top) | 反应窗口 `T = 2.0 s`（Nav2 `time_before_collision` 上界） |
| [ADR-0045](0045-ground-safety-layer-self-owned.md#top) 实测证据 E | 同平台同摩擦重复实测，**PASS 态对照臂**最小 `0.769 m` |

`max_offset = 1.0` 的余量只有 **1.7%**（`1.017 / 1.0`）。ADR-0045 的重复测量把下沿推到
`0.769 m` —— 两批数据的**最小值**不一致，差额 23%。这不是"某次没跑好"：
`0.769 / 1.398 = 0.55`（折扣），而 ADR-0004 当时记的折扣是 `0.72`。

**为什么不能靠"安全层少降速"解决**：`SLOW` 档按同比例裁剪 `v` 与 `ω`，
横移 ≈ `(v/ω)(1−cos ωT)` —— 比值不变，但 `ω` 变小让 `(1−cos ωT)` 变小。
ADR-0045 已实测：`slow_min_ratio = 0.2` 时 2 s 横移只有 `0.0002 / 0.030 / 0.048 m`，
即**把"能躲开"降级成"躲不开"**。所以"能力不够"不能由安全层让路来补。

## 决策

### (a) 收窄能力主张：`max_offset` 由 `1.0` → **`0.65 m`**

- 取值依据 = **方法修正后的重复实测下沿**（3 批 / 6 轮，见下表），
  不是"取个整数好看"，也**不是**沿用改造前那批 `0.769 m`。

#### 实测（同平台同摩擦，`tests/check_safety_calibration.py --stage slow`）

| run | trial | 2 s 横移 | 说明 |
|---|---|---|---|
| `calib-slow15` | 0 | **0.7140 m** | SLOW 窗口内无 `STOP_*` |
| `calib-slow15` | 1 | **0.6888 m** | 同上（**最小实测值**）|
| `calib-slow15` | 2 | 0.8156 m | 同上 |
| `calib-slow17` | 0 | 0.8137 m | 同上 |
| `calib-slow17` | 1 | 0.7801 m | 同上 |
| `calib-slow20` | 0 | 0.8769 m | 同上 |

- **最小 `0.6888` / 中位 `0.8137` / 最大 `0.8769 m`**；理想圆弧（按实测指令 `v=1.0, ω=0.96, T=2.0`）
  = `1.3981 m` ⇒ **折扣 0.4927 / 0.5820 / 0.6272**（取最小值 0.49 作为 `lateral_eff_ratio` 的保守下界）。
- 取 **`0.65 m`** = 在最小实测 `0.6888` 之下留 **5.6%** 余量。
- **曾一度取 `0.75 m` 并已推翻**：6 轮里有 **2 轮达不到** `0.75`（`0.714 / 0.6888`），
  那正是"配置说了一件车做不到的事"——与本篇要消灭的形态相同，故不能保留。

**失败样本如实登记**（不得用"接近成功"措辞）：`calib-slow15` 的 trial 0 / 1 两轮低于 `0.75 m`
（但都高于现行的 `0.65 m`）。另有 5 轮被**排除**且理由已定位：
2 轮"窗口内进入 `STOP_*`"（量到的不是 SLOW 下的横移）、3 轮"找不到满足 SLOW 档的起点"。
- 该值**同时**是 `agc_rl/config/rl.yaml` 的 `control.max_offset`（动作映射的满偏横向幅值）
  与 `agc_ground/config/ground.yaml` 的 `lateral_reach_required_m`（安全层反解 `SLOW` 下限的输入）。
  **两处必须同值**：不同就是"策略以为能做 A、安全层按 B 校验"的两套能力口径。
- **不得**用理想圆弧（holonomic 平移 / 常 yaw 率）推定本值；也**不得**按参数名推定。

### (b) 反应窗口 `T = 2.0 s` **保持不变**

- 不为迁就单一能力主张而放宽反应窗口：`T` 是三档距离的推导输入，
  改它要连带重标 `d_emergency / d_collision / d_safety`，代价远大于收益。
- 把"能力主张"与"安全判据"**解耦**：`T` 属于安全判据（"能不能停住"），
  `max_offset` 属于能力主张（"能躲多远"）。二者不是同一个量，不该互相迁就。

### (c) 安全层 `SLOW` 的终值：`slow_min_ratio = 1.0`（**不降速**）

- 收窄 `required` 到 `0.65 m` 后，`slowRatioFloor()` 反解出 **0.5461**（不再是 1.0）：
  `need = 0.65 / 0.55 = 1.1818 m`，而 `L(1.0) = 1.2402 m` ⇒ 满速**刚好**够，
  留出的降速空间只有 1 − 0.5461 ≈ 45%。
- **`slow_min_ratio` 的终值仍取 `1.0`**（不降速），理由与数值无关而与**语义**有关：
  实测折扣的最坏值是 `0.4927`，按它反解 `need = 0.65 / 0.4927 = 1.319 m > L(1.0) = 1.2402`
  ⇒ 用最坏折扣算，满速都达不到。故**不得**靠降速去"凑"能力，`1.0` 是诚实终值。
- 降低该值的唯一条件（三条缺一不可）：新的重复横移实验同时满足
  ① 目标位移 ≥ 要求、② 最差折扣不劣于已登记值、③ 安全判据（停车档）不被放松。
- **降低该值的唯一条件**：新的**重复横移实验**同时满足
  ① 目标位移 ≥ 要求、② 最差折扣不劣于已登记值、③ 安全判据（停车档）不被放松。
  三条缺一不可；**不得**用数学理想圆弧替代实测能力。

### (d) 能力承诺的边界（**局部逃逸 ≠ 安全层承诺**）

| 属于 | 内容 |
|---|---|
| **安全层承诺** | 在 `/agc/map` 覆盖范围内，以当前速度**能在进入障碍之前停住**；停不住就降档到零速 |
| **不属于安全层承诺** | "横向躲开障碍"、"绕过障碍"、"在 `T` 秒内横移 `X` 米" |

- **局部逃逸是 RL / 策略能力**：它取决于策略输出、底盘动力学、摩擦面，
  安全层只做"只裁不造"的收缩，**不**规划绕行、**不**改变方向。
- 因此"安全层让车停住了"**不得**表述为"安全层成功逃逸"；
  "`SLOW` 档没有降速"也**不得**表述为"安全层提供了逃逸能力"。

### (e) 三档取证的**形式**（`PASS → SLOW → STOP_COLLISION`）

- 取证场景必须是**独立场景轴的一格**（新增 `s19_static_static_safety_tiers`），
  且必须先通过**几何可行性闸门**（`tests/check_safety_scene_geometry.py`）：
  障碍顶面高度 / 相机高度 / GSD 像素尺寸 / goal 是否真在障碍另一侧 / 逼近段是否够长。
  几何不成立时**拒绝取证** —— 那时"全程 PASS"是安全层的正确行为。
- 判据**只读安全层自己的 `state`**（`/agc/ground/safety_status`），
  **禁止**从"速度变小"反推介入（那分不清"安全层限速"与"命令源本来就在减速"）。
- `STOP_EMERGENCY` **不要求**在"逐渐逼近"的整链里自然触发（实测 `s_brake(0.8) = 0.245 m`，
  车在 `d ≈ 1.77 m` 就被 `STOP_COLLISION` 的扫掠判据截住）。它的正确触发条件是
  "障碍单拍突现于 footprint 内"，属**故障注入**；由活节点核查
  `tests/check_safety_layer_live.py` 的 `d_near` 用例覆盖。

### (e2) 三档整链证据（**已取得**，2026-11-13）

场景 `s19_static_static_safety_tiers`（`yard` + `container_yard_b`，车 `(14,4)` 朝 −y、
goal `(14,-30)` 越过柜组），`backend:=full`，判据只读安全层自己的 `state`：

| 事件 | 时刻（相对任务启动）| 证据 |
|---|---|---|
| `PASS` | −3.0 s 起持续 | 出生点距柜组近边 20.78 m，扫掠区全为已知自由 |
| `SLOW` | **+9.4 s** | 进入 `d_collision..d_safety` 带（`slow d=2.017` 一类诊断）|
| `STOP_COLLISION` | **+12.2 s** | 进入 `d_emergency..d_collision` 带或制动扫掠撞格 |
| 车实测位移 | **11.33 m** | 证明车**真的开过**，不是"原地抖动" |
| 地图占据格 | 887 → 3234 | 证明障碍**真的进了 `/agc/map`**（不是"全程 PASS 因为图里没东西"）|

产物：`experiments/w5-ground-nav-safety/20261113-s19-tiers-10/metrics/safety_tiers.json`。

**几何前置闸门**（`tests/check_safety_scene_geometry.py`）在取证**之前**跑，六条判据全过：
相机高度 11.65 m、顶面 121.5 px（门限 4.5 px 的 27 倍）、goal 严格在柜组另一侧
（线段内部区间 `t∈(0.611, 0.801)`）、直连路径只穿柜组、起终点净空充足、逼近段 20.78 m。
**几何不成立时脚本直接拒绝取证**（返回 2）—— 因为那时"全程 PASS"是安全层的**正确行为**。

**档位抖动如实登记**：同一次取证里 `state` 在 `SLOW`/`STOP_COLLISION` 与 `BODY_INVALID`
之间翻转 **319 次**。根因是 `ground_odom_adapter` 的**微秒级负年龄**（`age = -0.004 … -0.024 s`）
被判成 `clock_anomaly` → `odom_valid=false`，**与安全层无关**，且在 s04 的历史 run 里同样存在。
按 [ADR-0017](0017-time-budget-and-clock-sources.md#top) 的口径（有符号年龄 + `age < 0` 即无效，
**不得**钳到 0），修它需要引入"容差参数"这一**新决策**，不在本篇范围内。
⇒ 档位**顺序**判据不受影响；但"某一档持续了多久"会被抖动切碎，**不得**用连续时长当证据。

### (f) 历史 L4 脚本的处置：**归档登记，不原地重写**

- `tests/` 下 5 个脚本仍以 `/collision_monitor/get_state` 判断"安全层是否 active"，
  该服务已随 Nav2 安全层退役：`check_scan_self_filter` / `check_scan_source_loss_stop` /
  `check_action_direction_escape` / `check_actuation_relay_hardening` / `check_baseline_path_replan`。
- 它们断言的是**旧链路的取证口径**，按产物分类属"历史证据档案"，
  **改写等于伪造历史**。故：**保留原文**，在[路线分支治理](../conventions/路线分支治理.md#current)
  5.3 台账登记"引用已退役对象、不接活跃门槛"，并按新口径**另立**替代判据。
- 替代判据 = `tests/check_safety_tiers_escape.py`（三档整链）+ `tests/check_safety_layer_live.py`
  （节点级三档 + 失效语义）+ `tests/replay_escape_trace.py`（横向能力的离线可重放）。

## 不做什么

- **不**放宽反应窗口 `T`；**不**改三档距离绝对值；**不**改安全层的判定顺序与失效语义。
- **不**把"横向逃逸"写进安全层的承诺；**不**用安全层降速来"补"能力缺口。
- **不**恢复静态先验地图、`scan` 或任何第二障碍来源（[ADR-0045](0045-ground-safety-layer-self-owned.md#inputs) 的输入契约不变）。
- **不**修改既有 `scenarios.yaml` 的格子来"顺手"满足几何 —— 新场景单独登记，旧格逐字保留。
- **不**原地重写那 5 个历史脚本。
- **不**新增 `xxx_mode` / `xxx_backend` / `xxx_source` 路线分支；不新增命令发布者；不改消息 ABI。

## Considered Options

- **保留 `max_offset = 1.0`，靠安全层少降速来"达标"** —— 被否：
  安全层的职责是"停得住"，不是"躲得开"；用它补能力缺口会把"停住"也一起削掉（ADR-0045 实测证据 E）。
- **延长反应窗口 `T` 到 2.5–3.0 s 以容纳 1.0 m** —— 被否：`T` 是三档距离的推导输入，
  改它要连带重标三档绝对值，代价与收益不成比例；且用户裁定保留 `T = 2.0 s`。
- **删除"逃逸能力"这一主张，只保留"停在障碍前"** —— 部分采纳：
  能力主张**收窄**而不是删除，因为 `max_offset` 仍是动作映射的真实参数（0.65 m 可达）；
  但**承诺边界**明确写成"局部逃逸属 RL/策略能力，不是安全层承诺"。
- **改 `s11`（goal 在立柱后）来取证** —— 被否：`pole` 0.3 m 见方、相机 3.39 m 近掠射、
  顶面 24 px 对门限 19 px（余量 5 px），实测拿不到连通域；这是**几何不合**，调参绕不过去。
  改既有格还会破坏历史 run 的可比性。
- **给取证台架喂静态地图** —— 被否：等于复活已退役的第二份障碍来源，违反 ADR-0045 (a)。
- **重写那 5 个历史脚本** —— 被否：它们断言的是旧链路口径，改写即伪造历史记录（ADR-0002）。

## Consequences

### 正面

- 能力主张与实测一致：`0.65 m` 在**方法修正后**的实测下沿（`0.6888 m`）之下，不再是"贴着余量的承诺"。
- 安全判据与能力主张**解耦**：改能力主张不必动三档距离，改三档距离不必动能力主张。
- `SLOW` 不再是一个"看起来在降速、实际上让车失去机动性"的档位；
  `slow_min_ratio = 1.0` 有明确物理理由与反解依据，不是手感值。
- 三档取证有了**独立、可判定、带几何前置闸门**的场景，而不是靠"某个场景碰巧有障碍"。
- 横向能力有了**离线可重放**的轨迹（`escape_arc_traces.json`），
  "最小值 / 折扣 / 失败样本"别人能自己重算。

### 代价 / 限制（如实登记，不得据此宣称能力）

- **`0.65 m` 仍只是该底盘在该摩擦面下的值**：换底盘 / 换摩擦 / 改 footprint 须重标
  （重标触发器与三档距离同一份清单）。
- **`SLOW` 事实上不降速**：在 `d_collision..d_safety` 带内车仍以原速度走，
  只靠 `STOP_COLLISION` / `STOP_EMERGENCY` 兜底。这是"能力贴着要求"的必然结果，
  但它意味着**安全带内没有减速缓冲** —— 该风险由三档距离（4.0 / 2.0 / 1.0 m）承担，
  不得再声称"安全带内会减速"。
- **`s19` 的期望终态是 `MISSION_FAILED / TIMEOUT`**：车被障碍挡住，到不了 3 m 跟踪圈。
  这是设计意图（与 `s11` 同结局语义），**不得**读成"场景坏了"。
- **横向能力的置信度有限**：样本量小（每批 3 次），且实测分布下沿不稳定
  （方法修正后 6 轮：`0.6888–0.8769 m`）。故 `0.65 m` 是**保守取值**而不是"平均能力"；
  任何"本车能横移 1 m"的表述都仍然不成立。
- **历史 5 脚本会如实 FAIL**：它们查的服务已退役。这不是回归，是历史档案的正常状态；
  活跃门槛不得引用它们。
