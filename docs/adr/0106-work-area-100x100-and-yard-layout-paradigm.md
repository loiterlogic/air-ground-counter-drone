# 作业区放大到 100×100 与场站式布局范式

## Status

accepted（2026-10-29，来源：用户裁定——"我考虑到在空地协同反无人机中 80\*80 可能不太够，改成 100\*100，然后重新布局障碍物分布和数量以及样式，样式要考虑现实世界中正常情况下是怎么分布的"；并明确要求"先学习别人是怎么做的，然后设计，一定是设计好大致分布再动手"）

## 背景与决策

P1-1 首版 `yard`（80×80 作业区、19 实体）由用户 2026-10-29 两轮反馈逐步修正（删双柱、中央加内容、
引入 `sphere` 与复合 `parts`）。用户随后提出**作业区尺度不足**，并要求**按现实分布重做**。

三条相互独立的事实促成本 ADR：

1. **尺度**：80×80 m 对"空地协同反无人机"的场地（建筑 + 堆场 + 道路 + 飞行空域）偏小；
   用户裁定放大到 **100×100 m**。
2. **分布范式**：首版布局的朝向/尺寸多样性是"手工堆出来的多样性"（13 种离散 `yaw`），
   **不像现实场站**。现实工业场站的正常分布是：**功能分区 + 网格对齐 + 道路留白 + 尺寸长尾 +
   中央空场保留**，不是均匀随机撒点。
3. **口径欠账**：P1-1 规格写了"障碍占作业区 **5%–12%**"的目标，但**没有任何检查在算它**；
   文档里流传的 `yard 覆盖 7.36%` 既不是并集（旧图 4.64%）也不是图元和（旧图 6.85%），
   **不可复现**。

**决策**：

1. **作业区 80×80 → 100×100 m（origin −50,−50）**，三张地图统一。栅格 200×200 @0.5 m。
   `minimal` 的**障碍几何逐值不变**（只放大作业区，保核查基线）。
   - `agc_perception/config/map.yaml`（standalone 回退副本）同步（断言 (c) 保一致）。
   - `scenario_reset.cpp` 的 **standalone 回退默认边界**由 ±40 改 ±50（该默认值**不是**几何真源）。
   - **8 字轨迹不改**：`rx=15 / ry=9 / h=2.5 / v=2.0` 是契约 [C1](../ROS2迁移交接文档.md#hard-constraints)，
     放大的是**作业区**，不是飞行包线。
2. **`yard` 按现实场站范式整体重做**：**29 实体 / 107 图元 / 27 复合体 / 13 小型件**，
   分 7 个功能区；`yaw` 以正交主向为主（11 种，含 5 个正交主向）；
   中央**装卸/操纵场坪保持空旷**（8 字飞行区）；周界为 30–34 m **分段长墙**（段间即门洞）。
3. **覆盖口径成文为"并集"**：并集投影面积 / 作业区面积；旧 `7.36%` 作废；
   `w6_geometry_check.py` 断言 (o) 新增 `coverage_union_in_5_12`，使该目标**第一次可自动判定**。
4. **三图作业区一致性纳入核查**：新增断言 (p)（`all_maps_uniform` + `is_100x100_origin_-50`）。
5. **实体数上限**：由 ≤20 放宽到 **≤32**（原上限是 80×80 时期为"精致化"定的；面积 ×1.56 且
   用户要求重做数量）。**仍保留上限**，不放任无序膨胀。

**先学后做（取证依据）**：① 本机**同版本、可运行**的 Nav2 世界
[`nav2_minimal_tb4_sim/worlds/warehouse.sdf`](/opt/ros/jazzy/share/nav2_minimal_tb4_sim/worlds/warehouse.sdf)（GZ Sim 8 / Harmonic，与本项目同引擎；
26 个 include）：货架**成排对齐**（`yaw` 仅 0 / 1.57）、隔离墩**成列**同 `x`、小件**成组贴近**功能区
——即"网格对齐 + 功能聚集"；② PX4 官方世界 `Tools/simulation/gz/worlds/baylands.sdf` 的
`<gui><plugin MinimalScene><camera_pose>` **固定相机预设**（官方可复现视角写法）；
③ 现实工业场站布局通则。**对照之后的结论**：范式的可迁移部分是"分区 + 对齐 + 留白 + 长尾"，
不是照抄某张地图的资产。

## Considered Options

- **只放大作业区、布局不动** —— 被否：用户明确要求"重新布局障碍物分布和数量以及样式"；
  且 80×80 的布局在 100×100 里会显得更空。
- **按"随机撒点 + 手工调朝向"做多样性** —— 被否：这正是首版的问题（伪多样性、不像现实场站）。
- **照抄 Nav2 warehouse 的资产/尺度** —— 被否：它是**室内仓库**（28×45 m），与本项目室外场站不同；
  可迁移的是**分布范式**，不是资产与尺寸。
- **用一根通长围墙闭合 100×100 场站** —— 被否（**技术原因**）：空中安全层是二维静态圆盘，
  半径 = 实体水平外接圆半径 ≈ 半长；100 m 墙的圆盘会吃掉全部空域、把 8 字轨迹判为不可行。
  → 采用 **30–34 m 分段长墙 + 段间门洞**，既贴现实（围墙本就按伸缩缝/柱距分段），
  又使每段圆盘远离 8 字空域。
- **把覆盖目标改成"图元和"口径**（旧图 6.85% > 5%，更容易达标） —— 被否：
  同一实体多图元堆叠（屋顶压在主体上）在"图元和"里被重复计数，**不是真实占地**。

## Consequences

- **真源**：[`world_geometry.yaml`](../../src/agc_sim/config/world_geometry.yaml)（minimal）与
  `maps/{yard,open_field}.yaml` 的 `work_area` 统一 100×100；schema 头部补 `sphere` / `parts`
  与"外接圆半径 ≈ 半长"的限制说明。
- **派生链**：`write_derived_map` / `compose_params` / `world_bringup` 均按 `work_area` 派生，
  无需改代码；`scenario_reset.cpp` 仅改 standalone 默认值。
- **核查**：[`tests/w6_geometry_check.py`](../../tests/w6_geometry_check.py) 断言 (o) 上限放宽 +
  新增并集覆盖；新增断言 (p)。**三图整体 PASS**。
- **行为**：`minimal` / `open_field` 的**障碍分布未动**（只有作业区变大）；`yard` 完全换新。
- **未决**：① 长围墙在"二维静态圆盘"安全层下的表达仍是**降级表达**（分段），
  若将来安全层升级为多边形/线障碍，可改回通长围墙；② 覆盖目标 5%–12% 的**并集**口径
  目前只对 `yard` 断言（`open_field` 是稀疏对照图，故意不达标）；
  ③ 本 ADR 未改 GUI 相机预设（另见 P1-1 轮次记录）。

## 修订（2026-10-29 21:00 · 视觉保真；来源：用户裁定）

**用户原话**：「建筑和地面精细度不高，能不能优化，比如材质改变，颜色分配优化。二是小型物体
（路牌这种）现在有点少，略微增加不要过分密集。网页看不了就不看了，学习本地能看的就行，
依旧设计好了再动手」。

### (a) 材质档 `finish`：**标量 PBR**，不引入外部资产

**先学后做（本机取证）**：`sdformat 1.11` 的
`material.sdf` 中 `<pbr><metal>` 的 `<metalness>` / `<roughness>` 是**标量**字段（默认 0.5），
**不需要贴图**；`gz sdf -p` 解析通过。因此可以在"不引入外部资产"的纪律内做真材质分化。

**决策**：几何真源新增**可选**字段 `finish` ∈ {`concrete`,`steel`,`paint`,`glass`,`rust`,
`asphalt`,`rubber`}（逐 part 可覆盖实体级；非法值**拒绝运行**；**缺省不写 = 旧行为**，
保证 `minimal` / `open_field` 与历史证据逐字节不漂移）。`world_bringup._material_sdf` 由
`finish` 生成 `<ambient>/<diffuse>/<specular>` + `<pbr><metal>`；`gz` 侧不支持的渲染器仍可回落
经典材质。**材质只进物理世界 `<material>`**，**不进**感知先验 / 占位栅格（材质不是几何）。

### (b) 配色分族 + 建筑细部 + 地面分层 + 略增小型件

- **配色**按功能分族、族内一致（生产仓储冷灰+银灰屋面；办公暖灰+深蓝绿玻璃带；罐区银白+
  单台标识罐暖橙；**集装箱同一排同色**；维修铁灰+亮蓝卷帘门；路缘家具按功能取色）。
- **建筑细部**：勒脚 / 女儿墙压顶 / 金属屋面板 / 逐层窗带（微凸真几何）/ 卷帘门 / 玻璃门厅 /
  台阶 / 屋顶设备 / 雨棚 / 月台 / 门廊柱；塔罐加基础环与爬梯；管廊加法兰。
- **地面分层**（`agc_world.sdf`，**不是**障碍）：基层混凝土 `ground_plane` + 沥青环形主路
  （东西各一 / 南北各一）+ 南门与北侧支路 + 中央混凝土作业坪 + 两处场坪；抬升 2–6 mm 避免
  共面 z-fighting；视觉与碰撞同源。**不进**几何真源 `obstacles` / 空中安全层 / 占位栅格。
- **略增小型件**（"不要过分密集"）：+7 实体（岗亭 / 道闸 / 大门标牌 / 指路牌 / 消防栓 /
  配电箱列 / 垃圾箱列），全部贴大门、环路与建筑，不撒进中央。
- **规模**：29→**36 实体**、107→**186 图元**、13→**19 小型件**；并集覆盖 10.33%→**10.89%**
  （仍在 5%–12%）。

### (c) 核查扩展（口径变更，需追认）

- 断言 (a)：`finish` 合法性纳入 schema 校验；
- 断言 (b)：新增 `material_finish_match` —— 逐 link 核对"声明 `finish` 的 part 在世界里
  `<pbr><metal>` 的 metalness/roughness **逐值一致**；未声明则**不得**出现 `<pbr>`"；
- 断言 (o)：实体上限 32→**40**（现 36，留余量）；新增 `material_kinds_ge_3`。

### (d) 未决（继续如实登记）

- **无贴图 / 无 mesh** → 材质只有标量 PBR + 纯色，出不了纹理细节（砖缝、锈斑、标线）。
  再往上必须走 [ADR-0068](0068-third-party-asset-provenance-license-and-hash-manifest.md) 的
  provenance / 许可 / 哈希登记。
- **GUI 窗口截图仍未取得**（本机 Wayland 无可用截屏工具）；本轮依旧用**同姿态相机传感器渲染**
  取证并标注 `backend=gz-offscreen-camera`，GUI 证据留待有截屏能力的环境补。
