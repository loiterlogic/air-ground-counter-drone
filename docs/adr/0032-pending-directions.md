# 待立项的后续方向（占位登记）

## Status

proposed（2026-11-06；未立项、无实施）

## 背景

`docs/plan/` 曾长期存放 4 个「后续方向占位」文件，内容是"状态未定、待调研"的意向，
不是任务（无出口判据、无执行链）。按 [任务计划规则](../plan/README.md#plan-index)
"当前在办：无""不维护候选清单"，这些文件不属于 plan 目录，已删除；方向本身不静默丢弃，
登记在本篇，供将来由用户提出时**新立**任务。

## 决策

以下 4 项**均未立项**，不得据本篇推定已实现、已批准或已有排期：

1. **空中障碍物真值地图传递**：由无人机侧取得障碍物真值，整理为地图形式发送给小车；
   未来视觉算法产生的障碍物地图也应共用同一表示。数据链与共享格式未定型。
2. **小车地图全局规划**：小车取得障碍物地图后做全局路径规划。当前是
   `placeholder_path_planner` 几何直连占位；`/agc/map` → costmap 链仅在 `ground_baseline`
   （`command_source=baseline`）下消费，属主线待建部分（ADR-0013）。
3. **小车轨迹跟踪算法调研**：调研可替换当前 LQR 轨迹跟踪的算法，期望表现更好、实现轻便，
   并能与后续 RL 局部避障配合。候选与比较口径未定。
4. **小车 RL 局部避障**：研究并实现 RL 局部避障能力。算法选择留到该任务开展时调研决定。

## 不做什么

- 不把上述任一项写成"当前能力"或"已知边界"；README 与对外文档不得引用本篇声称功能存在。
- 不在本篇里做方案对比、排期或验收判据—— 那是新立 plan 与对应 ADR 的事。
- 本篇**不授权**新增路线分支或参数开关（受 [路线分支治理](../conventions/路线分支治理.md#rule) 约束）。

## Consequences

- 方向信息有唯一、可查的归宿，且状态明示为 `proposed`，不会被误读为已实施。
- 任一项立项时，须在本篇把对应条目改为「已立项 → 见 ADR-NNNN」并新立 plan 文件；
  结档时按规则删除该 plan。
- 若某方向被用户明确否决，在本篇标注 `rejected` 与理由，不删除历史记录。
