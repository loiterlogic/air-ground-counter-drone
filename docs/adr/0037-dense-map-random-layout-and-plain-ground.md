# 高密度图改为随机撒点、间距加宽、地面按地图纯色化

## Status

（实体数 / 高度上限 / 出生位 / 环带判据等其余条款**继续有效**）。

取代（第二轮 +15%：最小间距 2.3 → **2.645 m**、实体 620 → **486**、区域仍 70×70）。

**相关**：[ADR-0007](0007-scene-geometry-single-source-and-layout.md#top)（几何单一来源；本篇 (a) 局部推翻其布局范式）、

## 背景

ADR-0036 落地 `dense_map` 后，用户实机启动 GUI 查看，提出三条修改（原话）：

1. **「我看了，地板怎么是s18的，不需要，换成纯色就行。」**
2. **「布局怎么这么规整，还是用 `refs/Fast-Planner/` 它这种随机生成吧」**
3. **「间距整体来看有点太小了，稍微加宽一点，大概15%就行」**

三条都不是缺陷，是**取向变更**。第 2 条与既有决策冲突，必须显式登记：

> ADR-0007 的 Considered Options 里写着「**随机撒点 + 手工调朝向做多样性 / 照抄 Nav2 warehouse 资产 —— 被否**：
> 前者是伪多样性，后者是室内仓库（28×45 m），可迁移的是分布范式不是资产。」

用户现在明确要求随机。这是**用户裁定推翻既有决策**，不是实现方自行改动。

另外查清一个结构事实：**地面不在任何地图 yaml 里**。沥青环路 / 场坪 / 路缘石 / 车位线 /
排水沟 / 碎石带 / 绿化带共 **38 个模型**全部内联在共享世界 `src/agc_sim/worlds/agc_world.sdf`，
四张地图共用同一份世界。所以"换地面"必须做成**按地图生效**，否则会连 `yard` 的地面一起改掉
（`yard` 的地面是花几轮做的，且有明度带断言 (q) 绑着）。

## 决策

### (a) 布局改为**随机撒点**（局部推翻 ADR-0007 的否决）

范式取自 `refs/Fast-Planner/uav_simulator/map_generator/src/random_forest_sensing.cpp`：
`uniform_real_distribution` 均匀撒点 + 与已放置点做距离拒绝采样。**只迁移范式，不抄资产/尺度**
（它是 40×20 m / 100+100 个障碍的室内风格，本项目是 100×100 m 室外场站）。

**关键纪律：随机 ≠ 不可复现。** 固定种子 `SEED = 20261110`，同种子同输出。
证据可复核，是"随机"能被接受的前提。

**位置与属性同源随机**：尺寸 / 高度 / 朝向 / 配色 / 形状（box 85% / cylinder 15%）全部随机抽取。

**推翻的范围必须写死**：ADR-0007 的"随机撒点 = 伪多样性"否决**仅在本图上失效**；
`minimal` / `yard` / `open_field` 的**结构化布局范式不变**，也不得据此新图援引。

### (b) 最小间距 **2.3 m**（上一版最近邻 2.0 m × 1.15）

> ⚠ **本节已被 [ADR-0044](0044-dense-map-second-gap-widening.md#top) 取代**（第二轮 +15%：2.645 m / 486 个）。
> 以下为当时的推导与容量实测，保留供追溯。

用户「加宽 15%」的落点：`MIN_GAP = 2.3 m`，作为**拒绝采样的下限**（不是均值）。

**实测取舍（必须记下来，否则会返工）**：间距加宽 15% 后，**同样的 60×60 m 区域装不下 620 个**：

| 撒点区 | gap=2.3 实测可放 |
|---|---|
| 60×60 m | **486** |
| 66×66 m | 583 |
| **70×70 m** | **620** ✓ |

⇒ 撒点区从 60×60 扩到 **70×70 m**，实体数保持 **620**。
**"间距加宽"与"密度不变"不能同时靠缩小区域达成**，这是面积约束，不是取舍偏好。

### (c) 地面按地图纯色化：`ground_style: plain`

新增**地图级可选字段** `ground_style`，取值 `layered`（缺省）/ `plain`：

- `layered` = 保留全部 38 个地表分层模型（`minimal` / `yard` / `open_field` **逐字不变**）；
- `plain` = 运行期把**地表装饰族**从生成世界剥离，只留基层 `ground_plane` 纯色。

实现：`world_bringup._strip_ground_decor()`，按**模型名前缀**判定装饰族
（`road_` / `apron_` / `curb_` / `bay_` / `drain_` / `gravel_` / `green_`），
在 `_inject_static_obstacles` 里、注入障碍**之前**做。非法值**拒绝运行**。

**为什么用文本块剥离而不是 XML 重写**：base world 有大量注释，XML 往返会丢注释，
使「生成世界 vs base world」的逐字节对比失效（核查 (b) 与 `none` 世界口径都依赖它）。

**纯视觉，不改任何物理**：地表装饰本就不进障碍几何 / 空中安全层 / 占位栅格（ADR-0009 口径），
剥离它们不影响碰撞、感知、规划。`ground_plane` 的 200×200 平面碰撞仍在。

**为什么用前缀而不是逐个列名**：新增地表件时无需再改判据；前缀族是既有分类的实例
（技能 map-design `#visual-vs-obstacle` 的"薄地表模型"一类）。

## 不做什么

- **不改** `minimal` / `yard` / `open_field` 的几何、出生位、高度、**地面**（逐值不变，已核查验证）。
- **不改** `ground_plane` 本身（纯色 = 它自带的材质；不新增/删除地面碰撞）。
- **不**把"随机撒点"推广到别的图：ADR-0007 的结构化范式对其余图仍有效。
- **不**为了随机而放弃可复现：种子固定，拒绝"每次跑都不一样"。
- **不**为某张图开例外判据：`ground_style` 是**地图级通用字段**，任何图都能用。

## Consequences

**正面**：
- 布局读起来像 Fast-Planner 那种不规则撒点（用户取向），且仍可复现；
- 间距加宽 15%（最近邻中位数 2.0 → **2.42 m**），"看起来太挤"的问题解决；
- 地面可纯色化，且**不影响** `yard` 的既有外观与明度带断言；
- `ground_style` 是通用字段，将来别的图想纯色化不必再改代码。

**代价 / 限制（如实登记）**：
- **面积约束**：间距加宽后撒点区必须从 60×60 扩到 70×70 才能保住 620 个实体。
  若将来要求"区域不扩大"，则实体数必然降到约 486 —— **不能两者都要**。
- **随机撒点的可解释性下降**：规则栅格能一眼看出"成排成列"（现实场站特征），
  随机撒点**失去**这个现实感。这是用户明确的取向取舍，不是提升。
- **`plain` 地面失去地表分层信息**：`yard` 的道路/场坪在视觉上区分功能分区；
  本图纯色后**没有**这类视觉线索（本图也不需要——它不测视觉保真）。
- **8 字净空仍为负**：随机撒点后最紧实体变化，但结论不变（本图不跑预设轨迹）。
- **渲染/物理开销仍未实测**：620 个静态模型，T2 真实实验才能量。
