# 论文方向解禁与私人文档隔离

## Status

accepted（2026-11-07，用户裁定；2026-11-07 按用户二次裁定收窄）

## 背景

- **2026-10-29 方向裁定**（见 [AGENTS.md](../../AGENTS.md)）：「迁移推进与论文优先**暂停**，先确保项目『完成』」；
  该暂停事实由 [ADR-0025](0025-publishing-boundary-and-retirement.md#top) 承载，原开关文件 `PAUSED.md` 已于
  2026-10-31 退役。
- 2026-11-07 用户裁定 **「整体解除暂停，论文方向正式立项」**。这是方向级变更，按
  [ADR-0002](0002-docs-source-of-truth-and-reference-discipline.md#top) (a) 须由一篇入库 ADR 承载，
  不得静默假设、不得只改入口索引了事。
- 同日用户二次裁定（收窄本 ADR）：论文相关材料**仅供本人阅读，不入库、不公开其框架或演化过程**；
  且**必须与代码绝对隔离**——本机私人目录内任何文件不得被任何代码引用、不得与代码产生任何关联，
  **包括文件名**。需要让本仓「知道有这么回事」时，只由本 ADR 承载，不写内容、不写路径去描述材料本身。

本 ADR 只裁定**方向状态**与**隔离红线**；不写任何研究问题、贡献、方法、目录布局或产物分类
（那些属私人材料，不入库）。

## 决策

### (a) 解除论文方向暂停

- 2026-10-29 的「迁移推进与论文优先暂停」中，**「论文优先暂停」部分解除**；论文方向自此**正式立项**，
  可作为任务链的合法来源。
- [AGENTS.md](../../AGENTS.md) 中该句改为「现行方向已由 [ADR-0034](0034-paper-direction-resume-and-doc-isolation.md#top) 解禁」，
  保留 2026-10-29 裁定作为历史事实，**不全文抹除演进**（[ADR-0002 (c)](0002-docs-source-of-truth-and-reference-discipline.md#top)）。
- **迁移推进**不在本次解禁范围内：本条**不**重启 ROS1 → ROS2 迁移推进；其状态仍按 [ADR-0025](0025-publishing-boundary-and-retirement.md#top) 执行。
- 解禁**不等于**放行任意源码改造：每次改造仍按 [任务计划规则](../plan/README.md#plan-index) 单独立项（结档即删），
  遵守 [路线分支治理](../conventions/路线分支治理.md#rule)（无用户明确允许不得创造路线分支）、
  [契约真源](0020-package-boundaries-and-runtime-topology.md#hard-constraints)（发现硬约束未满足立即停止并报告）、
  与 [先学后做](../../AGENTS.md) 的纪律。

### (b) 私人文档隔离（硬红线）

用户 2026-11-07 二次裁定，逐条为硬约束：

| # | 红线 |
|---|---|
| 1 | 论文相关材料是**仅本人阅读的本机私人文档**，**不入库**；`.gitignore` 只保留一条通配忽略，不登记文件名、不描述内部布局 |
| 2 | **不得被任何代码引用**：`src/` / `scripts/` / `tests/` / 配置 / launch / 任何构建或测试流程，一律不得读取、打开、解析、硬编码、import、glob、或按名字匹配该目录内任何文件 |
| 3 | **不得与代码产生任何关联，包括文件名**：代码里不得出现该目录名、其内文件名（含 basename、去扩展名、变体字符串）作为字面量、常量、配置项、注释指向或字符串拼接片段；反之，私人目录内文件也不得成为任何代码生成 / 校验 / 索引 / 文档链接核查的输入 |
| 4 | **不得被本仓文档引用**：`AGENTS.md` / `README.md` / `GLOSSARY.md` / `docs/**`（本 ADR 与 `.gitignore` 的忽略行除外）/ 配置中，不得出现指向该目录或其内文件的路径、链接、文件名 |
| 5 | **不进本仓产物分类表**：该目录不是本仓产物，[目录与命名规范 #10](../conventions/目录与命名规范.md#10-产物分类与生命周期) 不列它、不定义它的生命周期 |
| 6 | **本 ADR 是唯一例外**：只有本 ADR（入库）可以「提及存在这么一类隔离物」，且只写规则、不写内容、不写文件名、不写内部路径 |

> 判据（可判定）：删除该私人目录后，本仓**构建、测试、演示、文档链接核查、`.gitignore` 之外的一切**必须照常通过；
> 在 `src/` / `scripts/` / `tests/` / 配置 / launch 中检索该目录名及其内文件名，**命中数必须为 0**。

### (c) 需要引用时怎么做

- 若日后某条决策确需「让本仓知道」相关约定，**只**新建 / 修订 ADR 来承载（本 ADR 或其 amends），
  且只写规则；**不**在 ADR 里写私人材料的内容、路径或文件名。
- 私人材料的演化过程（版本、改动记录等）只在私人目录内自行保留，不入库、不进任何本仓台账。

## 不做什么（边界）

- **不**在本 ADR 或任何入库文件里写任何论文题目、贡献点、方法、实验结论、材料目录布局或文件命名。
- **不**推翻 [ADR-0022](0022-research-propositions-and-decision-rule.md#top) 的科研命题与判定规则；解禁的是「方向」，不是「科研口径重开」。
- **不**重启迁移推进；**不**自动放行源码改造。
- **不**把私人目录列为产物、技能、规范、归档或任何被本仓消费的类别。

## Consequences

- 正面：方向状态有合法身份；隔离是显式硬红线且可判定（删目录 + 零命中检索）；入库痕迹压到最小。
- 负面：私人材料不入库 ⇒ 换机器丢失、无法 review / 回溯。这是用户明确选择，本 ADR 不再展开代价、不提供「日后改入库」的迁移方案（避免暴露框架）。
- 中性：`AGENTS.md` 方向句由「暂停」改为「已解禁 + 指向本 ADR」，历史裁定仍可读；
  `docs/adr/README.md` 索引由 `scripts/adr_index.py` 重新生成。
