# 项目定位：全新重写、纯仿真交付与研究主线

## Status

accepted（2026-11-02 由 ADR-0001 / 0006 / 0009 / 0013 / 0014 / 0016 / 0017 合并；各条结论均未被后续决策推翻，
仅执行范围一项已随时间失效，见「已失效的部分」）

## 背景

本项目（大创）在 2026-10 前后确定了一组**上游定位决定**：交付物是什么、代码从哪来、验收环境是什么、
论文主线是哪条、本次做到哪里为止。这些决定不是彼此独立的——「重写即交付物」决定了「不能有第二套系统」，
「纯仿真」决定了「拦截只能用行为级等价」，而这些又共同决定了协同回路与执行范围。

分散在多篇 ADR 里的后果是：每篇都要重述一遍同样的前提，改一次口径要改五处，且引用链越绕越深。
本 ADR 把它们合并为一篇，**只保留仍然约束今天工作的结论**。

## 决策

### (a) 交付物 = 本仓库本身

- **软著登记对象** = `src/` 下的包；
- **「平台搭建」交付物** = 本**仿真**平台（世界 + 车 + 无人机 + 协同栈），不是实物平台；
- **论文素材** = 本仓库仿真实验产物（`experiments/`），论文在本仓库内完成。

三者**共用同一份代码与产物**，接口语义与终态口径一律以[契约真源](../ROS2迁移交接文档.md#hard-constraints)
为准，**不得为凑交付物而分叉**。申报书里的「研究进度安排（阶段）」**不作为执行约束**。

### (b) 全新重写，而非逐包等价迁移

新项目根 = `/home/chen/AGC`（colcon 根即项目根）；ROS2 代码、实验产物、文档三类结构**从零搭建**新规范。
旧 ROS1 树**降级为只读归档参照**，只用于行为语义对照，**不作代码来源**—— 不得复制粘贴其代码，
也不沿用其目录、命名、格式与任务粒度（旧树已于 2026-10-31 退役删除，见 [ADR-0025](0025-publishing-boundary-and-retirement.md#top)）。

### (c) 纯仿真为唯一验收环境

以 **GZ Sim + PX4 SITL** 为唯一验收环境；传感器口径、时钟、PX4 链路按仿真标定。
为实机**预留可替换接口**（传感器抽象、链路抽象），但**不承诺**支持真机，也不为其牺牲仿真重构的自由度。
投入力度定为**轻量**：只保持算法 / 接口边界整洁，不建完整抽象层。

原依托的硬件拦截平台与研究生团队已撤离，项目**完全依托仿真**：「移动式反无人机平台」等物性对象以 GZ Sim 模型 /
插件表达；**电磁干扰 / 物理拦截**类操作**若在仿真中可实现**（先按「先学后做」核查既有做法，再定抽象层级）则纳入
范围，否则不做（**待定**，不静默假设）。

### (d) 按职责域组织，不按时间序组织

重构按**职责域**切 workstream，每个 workstream 自带独立验收口径；执行顺序由**显式依赖图**派生，
不按写死的 P0–P6 时序推进。硬约束回归挂到**首次使该约束可验证**的 workstream，而不是每阶段一律重跑。

### (e) 研究主线 = 移动式主动拦截系统，空地协同路径规划为核

- **主**：移动式主动拦截系统（系统 / 集成论文）；
- **核**：空地协同路径规划 / 制导—— 本仓代码即其载体，不另立系统；
- **RL 地面控制** 与 **多源信息融合** **不放弃**，但归入「项目结束后的后续研究」；相关代码与 workstream
  **不得因此删除**，只调整优先级。在论文叙事中它们是**手段**，不是主线。

### (f) 空地协同回路：空中常开 standoff 跟踪 + 自保，地面自主规划

- **无人机**：对目标**常开跟踪**（非可选），保持安全间距，目的是不丢目标并持续提供观测；同时负责自身飞行安全。
- **地面车**：**消费**无人机观测数据，**自主规划**自身路径。二者**不共享单一规划器**—— 把规划抬到空中
  会削弱「地面自主规划」这一研究点。
- 数据流：UAV 感知 → 融合 → 全局 map → 地面规划消费（`AirObservation` / 融合 / `map_adapter` 骨架）。
- 因此契约硬约束 **** 定为「跟踪常开 + 安全间距 + 目标新鲜度冻结」，取代原「跟随默认关闭（`--follow` 开启）」。

## Considered Options

- **逐包等价迁移 + 局部优化** —— 被否：会把旧项目（尤其实验目录）的结构错乱一并继承。
- **重写仅作研究载体，软著 / 平台另立一套** —— 被否：实际交付物就是本仓库，拆分会让三者口径彼此漂移。
- **迁移后必须支持真机** —— 被否：过早引入实机约束会牵制重构。
- **以 RL 或信息融合为本次论文主线** —— 被否：系统论文最容易兑现软著 / 平台 / 创新点；B / C 降为后续而非放弃。
- **UAV 主动给全局路径 / 子目标、地面跟随** —— 被否：削弱「地面自主规划」这一研究点。
- **维持「跟随可选 / 默认关闭」** —— 被否：协同感弱，无法兑现「空地协同」作为论文核心。

## 已失效的部分（保留以便读旧文，不再约束今天）

- 「本次攻关范围出口到 ****」与「拦截落于/、不新增 workstream」：当时的阶段划分与出口已随
  迁移推进暂停而失效，现行执行入口是 [`docs/plan/`](../plan/README.md#plan-index)。该决定**唯一仍然有效**的
  内核是：拦截**不单独立项**，落在地面侧任务与评估链路内。
- 「/归项目结束后后续」：/后续实际已执行并结档，见
  [ADR-0021](0021-w8-gui-headless-equivalence.md#top)、[ADR-0022](0022-w7b-research-propositions-and-decision-rule.md#top)。

## Consequences

- 接口设计保留可替换边界，实机适配作为独立后续任务，不在当前 workstream 范围内。
- 软著、平台、论文三者共用代码与产物；契约 [终态语义](../ROS2迁移交接文档.md#terminal-semantics) 的
  「阶段 A / 阶段 B」口径由此消解（阶段 A = 跟踪，阶段 B = 拦截）。
- 拦截相关决策见 [ADR-0011](0011-interception-and-fire-control.md#top)；协同回路的具体实现落在
  地面规划（[ADR-0013](0013-ground-planning-path-contract.md#top)）与感知（[ADR-0009](0009-perception-truth-derived-and-vision-path.md#top)）。
