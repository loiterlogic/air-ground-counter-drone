# 文档真源分层与引用纪律

## Status

accepted（2026-11-02 由 0002 / 0066 合并；结论未变）

## 背景

项目早期最大的文档成本不是「写」，而是「同一件事写在多处、然后各自漂移」：契约、进度、规格、决策各自有一份
状态表，改一处要追五处；跨文档引用用章节号，重排一次就全断。结构评审点名的三个病灶是：accepted 决策的
**历史正文与后续修订残留并存却缺当前适用关系**、相对链接**层级不符**、出现**第二状态表**。

评审同时给了口径：**残留措辞不等同进度未完成的裁决**，**保留历史、不全文重写抹除演进**。

## 决策

### (a) 每类信息只有一个家

| 信息 | 家 |
|---|---|
| 不可变约束（硬约束 / 坐标系 / 终态 / 接口语义） | [契约真源](../ROS2迁移交接文档.md#hard-constraints) |
| 当前方向 / 进度 | [`docs/plan/`](../plan/README.md#plan-index) |
| 难以逆转的决策 | `docs/adr/` |
| 术语 | [`GLOSSARY.md`](../../GLOSSARY.md) |
| 历史规格 | `docs/archive/specs/`（本地保留、不发布） |
| 工程规范（目录 / 命名 / 产物生命周期） | [`docs/conventions/`](../conventions/目录与命名规范.md#10-产物分类与生命周期) |

下游**只引用、不复述**上游 —— 复述即制造第二真源。契约类约束**只存在**于契约真源，规格三件套与 Runbook
对硬约束只引用、不复制数值。

### (b) 引用一律用稳定锚点，禁用章节号

- 跨文档引用写成 `<文件>#<锚点>`（可点击链接）；**禁止**章节号记法 —— 重排章节不得使引用失效。
  章节编号只保证本文件内自洽，不能作为跨文档坐标。
- **纪律 / 禁止句**里被点名的锚点名称（如「契约 `#hard-constraints`」「Runbook `#status`」）作为**命名引用**保留，
  但**可导航引用一律给出链接**，不散落裸锚点文本。
- 相对链接层级按**生成物所在层级**计（如规格三件套在 `docs/archive/specs/<ws>/` → 指向项目根用 `../../../`）；
  模板内代码块的相对层级同样按生成物计，不按模板自身位置计。

### (c) 适用关系节：保留历史，标明现行

历史正文与现行决策并存的决策文档**须**有「适用关系」节，显式给出 **supersedes / amends / 适用范围 / 决议锚点**。
**保留历史正文**（不全文重写），下游**只链接现适用**的决策。旧值允许留在正文里，但必须**显式标「作废」**，
不能留下并存歧义 —— 有并存歧义时以标注的现行为准，而不是以「最后一段」为准。

### (d) 进度唯一真源，禁止第二状态表

进度**只**引用 [`docs/plan/`](../plan/README.md#plan-index)；规格 / checklist **不**维护第二状态表。
**残留措辞不**作为「进度未完成」的裁决 —— 以现行索引为准。同样，**不**凭推断改写完成状态：完成状态由证据决定。

### (e) 不重写历史链接

指向已退役入口 / 已归档产物的悬挂引用，**不重写**为「当时不存在」的名字（那是伪造记录）。做法是加「现适用」注记
读作同一拓扑；退役入口名与现入口的对应关系以注记形式保留在正文里，归属到下一次正式冻结前统一处置。

### (f) 规格模板的占位符单列

规格模板的占位符（`<WS>` / `<名称>` / `<ws-id>-<slug>` / `<锚点>` / `<#>`）**单列成表**，不散落在正文句子里；
模板的进度条目引用现行索引而非第二状态表；模板内代码块的相对层级按生成物层级计。

## 不做什么（边界）

- **不**用单一大文档承载全部内容（会重新制造章节号交叉引用错乱与重复内容各自漂移）。
- **不**全文重写各决策文档抹平演进（抹掉演进轨迹，读者无法复核历史结论）。
- **不**在任何地方维护第二状态表以「对齐」（重复真源，与索引冲突）。
- **不**重写指向已退役产物的悬挂链接（会把历史证据日志改成伪造记录）。
- **不**为消除悬挂引用而删除历史正文或历史产物引用。

## Considered Options

- **单一大文档承载全部内容** —— 被否：已实测出现章节号交叉引用错乱与重复内容各自漂移。
- **全文重写各决策文档抹平演进** —— 被否：抹掉演进轨迹，无法复核历史结论（违背评审「保留历史」）。
- **在各处维护第二状态表以「对齐」** —— 被否：制造重复真源，与索引冲突。
- **重写指向已退役 / 已归档产物的悬挂链接** —— 被否：会把历史证据日志改成「当时不存在」的名字，属伪造记录。
- **仅改被点名的个别文件** —— 被否：不解决层级 / 锚点 / 模板的**系统性**不一致。

## Consequences

- 重排章节不再使跨文档引用失效；改一处口径只需改一个家；读者按「**现适用**」决策执行，历史分歧仍可追溯
  （适用关系节 + 历史正文并存）。
- 决策文档允许「只追加、不重写」。本仓 2026-11-02 的决策合并（112 → 27）是**一次显式的例外**：只做同域归并 +
  去重，逐条结论不变，映射表随合并记录留档。
- **代价 / 限制**：悬挂引用（指向已退役入口与已移除 / 已归档实验产物）**登记但不重写**，读者须靠「现适用」注记
  自行换算；同一批悬挂引用要到正式冻结前才统一处置。
- 契约冻结的 9 消息 / 服务 ABI、唯一执行口语义**不受本决策影响**。
