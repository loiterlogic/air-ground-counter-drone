# 视觉识别接入任务决策路径（真值派生 → 视觉驱动）

## Status

accepted（2026-10-29，来源：用户裁定——"要接进任务决策（用视觉替代真值感知）"）

## 背景

[ADR-0020](0020-perception-as-truth-derived-simulation.md) 定本项目感知口径为**真值派生仿真**：`air_perception` 以世界真值为输入、按通道模型（丢包 / FOV / 遮挡 / 噪声）产出观测，**不做**真实视觉检测。

现用户裁定：另一同学开发**空对地场景识别视觉算法**，且其识别结果**要接入任务决策**，即用视觉识别**替代**真值派生感知作为决策输入。

这与 ADR-0020 的口径**直接冲突**，按 [AGENTS.md](../../AGENTS.md) 铁律"未决事项不得静默假设"，必须显式裁定，不得在实现里偷偷切换。

## 决策

**新增"视觉驱动感知路径"作为与真值派生并行的第二条决策输入路径，二者互斥选择、显式标注、不可混读。**

具体：

1. **两条路径共存**，由单一参数选择（不新增第二命令者、不改 9 消息 ABI）：
   - `truth`（既有，ADR-0020）——真值派生 + 通道建模，默认值，保证既有证据链与核查不变；
   - `vision`（本 ADR 新增）——消费机载相机图像 → 识别节点 → 检测结果 → 融合 → 任务决策。
2. **视觉路径必须可回退**：无模型 / 模型失败时输出空检测，系统**显式降级**并标注，**不得**静默回退到真值（否则无法区分是哪条路径产生的结论）。
3. **证据必须可区分**：任何 run 的 `summary.json` / manifest 必须记录 `perception_path=truth|vision`，且记录视觉模型的标识（名称 + 版本/哈希）。没有这个字段的实验产物**不得**用于比较或论文结论。
4. **真值仍可用于评估**：真值可作为**评估对照**（ground truth 评分），但**不得**作为 `vision` 路径的决策输入——这是"视觉驱动"的定义。

## Considered Options

- **纯视觉替代（删除真值派生）** —— 被否：会一次性作废 W4 全部既有证据与核查，且丢失可对照基线；违反"暂停期间不改既有已验收能力"。
- **两条路径并存 + 显式选择** —— **采纳**：可保留既有证据，可做 truth vs vision 对照（本身就是有价值的实验），且回退路径清晰。
- **视觉仅展示、不接决策** —— 被否：用户明确要求接决策。

## Consequences

### 必须做

- `perception_path` 参数进入契约 [参数入口](../ROS2迁移交接文档.md#params) 清单（由 launch 单一设置，节点不得覆写）。
- `run_logger` 的 `summary.json` 增加 `perception_path` 与视觉模型标识；**这是新增字段，不改既有字段语义**。
- 视觉路径的检测结果**不得**写入既有 `TargetObservation` 的"真值派生"语义字段而不加区分——需新增 `DetectionArray` 或带 `source=vision` 标记的等价物（具体形态在 P1-4 实现时定，但**必须可区分**）。
- 评估时 `truth` 路径作为**基线臂**保留，用于量化"视觉替代真值"的代价（检测率、误检、时延、对终态的影响）。

### 不得做

- 不得把视觉检测结果表述为"真值"或与真值混用。
- 不得在 `vision` 路径下静默使用真值坐标补齐检测（例如用真值位姿"修正"检测框）——那会让视觉贡献不可信。
- 不得删除或改写 ADR-0020；本 ADR **扩展**其适用范围，不否定其历史正确性。

### 表述纪律（论文 / 答辩）

- `truth` 路径的结果必须标注"受控感知仿真口径"（ADR-0020 原文要求）。
- `vision` 路径的结果必须标注"视觉识别驱动"，并给出检测性能（召回/精度/时延）。
- **不得**把 `truth` 路径的结果当作视觉能力，也**不得**把 `vision` 路径的结果外推为真实部署能力（仍是仿真图像）。

## 待定（实现时闭合，不阻塞本裁定）

- 检测结果的消息形态（新增 `DetectionArray` vs 扩展既有消息）——**倾向新增**，因既有 9 消息字段与顺序不得变更。
- 视觉检测如何进入 `air_fusion`（新增一路输入 vs 独立融合节点）。
- 相机挂载点与视角（机载前视 vs 下视），见 [P1-4](../archive/completion-20261031/p1-4-视觉算法接入.md#p1-4-goal)。
