> 索引：[项目完成路线](README.md#plan-index)。前置：[P1-1](p1-1-地图与场景资产.md#p1-1-goal)、[P1-2](p1-2-一键演示入口.md#p1-2-goal)、[P1-3](p1-3-任务可观测与演示呈现.md#p1-3-goal)（[P1-4](p1-4-视觉算法接入.md#p1-4-goal) 可并行）。
> 约束引用：[ADR-0081 公开仓库边界](../adr/0081-public-repo-publishing-boundary.md)、[第三方资产与许可](../conventions/第三方资产与许可.md)、[C3 GUI 验收](../ROS2迁移交接文档.md#hard-constraints)。

## 为什么做

现在项目根只有 `AGENTS.md` 和 `GLOSSARY.md`，**没有 README**。实测：

- 陌生人（老师、评审、同学）打开仓库，**不知道这是什么、怎么跑**；
- 没有截图/视频，**看不出做成了什么样**；
- 已知缺口（占位捕获、真值感知、无实机）散落在 ADR 里，**没人会去翻 102 篇 ADR**。

代码能跑 ≠ 项目完整。**交付物是"完整"的最后一块。**

## 要做什么

### 1. 根目录 `README.md`（最重要）

**目标：陌生人 10 分钟内能跑起来。**

建议结构（控制在 ~150 行）：

```markdown
# AGC · 空地协同反无人机仿真

> 一句话：同一世界、同一时钟下，无人机 + 地面车协同完成"发现—跟踪—抵近"任务。

![演示截图](docs/plan/assets/demo.png)

## 这是什么
- 3–5 行讲清问题、方案、当前状态
- 明确：纯仿真、ROS 2 Jazzy、Gazebo Harmonic

## 快速开始
```bash
./run_demo.sh doctor    # 环境自检
./run_demo.sh           # 跑默认演示
```
（3 条命令以内；不要让人先读 5 页环境配置）

## 演示看到什么
- 状态含义表（引用 P1-3）
- 截图/GIF：启动、跟踪中、终态

## 系统结构
- 一张图：包边界 + 数据流（引用 docs/conventions/包边界.md）

## 目录导航
- 只列 8 个包 + 关键目录，每个一行

## 已知边界（诚实清单）
- 捕获裁决为闭式占位（ADR-0024）
- 感知为真值派生（ADR-0020）
- 无实机验证（ADR-0009）
- 视觉识别可插拔，默认无模型（P1-4）

## 文档
- 当前方向：docs/plan/
- 契约：docs/ROS2迁移交接文档.md
- 决策索引：docs/adr/README.md
```

**关键要求**：

- **截图必须是真实运行截图**，不能是示意图；
- **已知边界必须写**（这是可信度来源，不是减分）；
- 不写"未来将实现 XX"（未做的就列在已知边界，不承诺）。

### 2. 演示视频 / GIF

| 产物 | 规格 | 用途 |
|---|---|---|
| 短 GIF（10–15 s） | 800px 宽，≤ 5 MB | README 顶部 |
| 完整视频（2–3 min） | 1080p，含旁白或字幕 | 答辩/提交 |

**录制要点**：

- 必须**有头（GUI）**录制（[C3](../ROS2迁移交接文档.md#hard-constraints) 要求定性场景 GUI）；
- 画面里要有**状态面板**（P1-3），否则看不出在干什么；
- 结尾要有**终态与结果**，不能只录"车在动"；
- GIF 落 `docs/plan/assets/`，完整视频**不入 git**（体积），给网盘/本地路径。

### 3. 系统结构图

一张图讲清包边界与数据流。**优先复用现有真源**：[包边界](../conventions/包边界.md) 已有职责定义，[接口分层](../conventions/接口分层.md) 已有分层。

建议格式：Mermaid（可版本控制、可 diff、GitHub 原生渲染）或 drawio 导出 PNG。

内容至少含：

- 8 个包（`agc_sim` / `agc_air` / `agc_ground` / `agc_perception` / `agc_control` / `agc_task` / `agc_rl` / `agc_msgs`）；
- 数据流：GZ ↔ 桥 ↔ 感知 ↔ 任务 ↔ 控制 ↔ 执行口；
- 外部依赖：PX4 / uXRCE / Nav2。

### 4. FAQ / 排障

把 [整链排障速查](../conventions/整链排障速查.md#preflight) 的**高频项**摘成面向新人的 5–8 条：

| 症状 | 原因 | 处置 |
|---|---|---|
| `./run_demo.sh doctor` 报工具链缺失 | 未构建 PX4 | 见 `toolchain/README` |
| 启动后卡在"等待 PX4" | 错峰 25/35 s，正常 | 等，或看进度提示 |
| `ros2 node list` 为空 | `ROS_DOMAIN_ID` 非 0 / 发现范围错 | 恢复默认 |
| 有残留进程 | 上次没干净退出 | `./run_demo.sh stop` |
| 图像黑屏 | 渲染后端 / headless | 见 P1-4 风险节 |

> FAQ 放在 README 内或独立 `docs/faq.md`，**不要**复制整篇排障速查（那是给开发者的）。

### 5. 基础自动化测试

现在 `tests/` 有 **57** 个核查，但**没有"一次跑完并全绿"的入口**。需要：

- 一个**冒烟集**（约 5–10 个），能在 5 分钟内跑完，全绿；
- 命令：`./run_demo.sh test` 或 `python3 tests/run_all.py --smoke`；
- 内容建议：几何派生链（`w6_geometry_check`）、消息定义、文档断链（P0-3 新增）、索引一致（P0-4 新增）、单元测试（`colcon test` 里的 gtest/pytest）。

> **不是**要求 57 个全绿（很多需完整 SITL，耗时且依赖环境）；而是**有一个可信的冒烟门槛**。

### 6. 干净环境验证

**这是"完整"的硬证据**：在一台**没跑过本项目**的机器（或清空 `build/ install/ log/` 后）按 README 走一遍。

记录：

- 从 `git clone` 到看到画面，**耗时多少**；
- 卡在哪一步、README 哪句不清楚；
- 修正 README，再走一遍。

> 至少走 **1 轮**；有第二个人（同学）独立走一遍更好——**自己写的 README 自己永远看得懂**。

## 风险与注意

- **最大风险：README 写给自己看**。必须让**没参与的人**按 README 走一遍，记录卡点。
- 截图要**新**：改了地图/界面后要重拍，别用旧图（旧图会暴露"文档没跟上"）。
- 已知边界不要写成"缺陷清单"式的自我否定，要写成"**当前能力范围**"——同样的信息，专业的表达。
- 视频/大文件**不入 git**（`.gitignore` 已有 `experiments/`；视频建议放 `docs/plan/assets/` 仅 GIF，完整视频外部链接）。
- 不要在 README 里复述契约约束（[ADR-0002](../adr/0002-docs-source-of-truth-layering.md)：下游只引用不复述），用链接。
- 公开仓库边界（[ADR-0081](../adr/0081-public-repo-publishing-boundary.md)）：`.trae/`、`experiments/`、`reference/` 不发布；README 里的路径不要指向它们。

## 非目标

- 不做项目网站 / 在线文档站。
- 不做安装包 / Docker 镜像（未来可议；当前以"本机能跑"为准）。
- 不补论文内容（用户已裁定论文后置）。
- 不美化历史（不重写 ADR、不粉饰已知缺口）。
