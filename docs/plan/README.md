## 并行授权（现行口径）

并行**不是默认能力**：需**用户授权**后才能同时开多条独立任务链。硬边界（文件隔离 / 独占资源 /
CURRENT 单一写入 / 冲突先停后报）已固化进[协作协议](../../.coordination/README.md#parallel)。
上一批次的落地记录见[归档批次](../archive/improvements-20261031/README.md#parallel)。

## 纪律（立任务前必读）

- 一次只推进一个任务链；独立链可按用户授权并行（[协作边界](../../.coordination/README.md#parallel)）。
- 每单先学习、后设计、再实施；仿真/构建独占，CURRENT 由 Leader 独占写。
- 资源按"总时长 + 单次时限 + 明确边界"授权，次数只记账；连续 4 轮无区分性新证据才熔断。
- **不弱化**：契约红线、独立验收、失败证据留痕（[协作协议](../../.coordination/README.md#protocol)）。
