# 任务计划（Plan）· **规则**

> **本目录是临时工作区，不是真源。**
> 这里的文件**只回答"这一轮做什么、做到什么算完成"**，任务结束即**删除**。
> **任何地方不得长期引用本目录的文件**—— 结论必须写进永久归宿（[ADR](../adr/README.md#adr-index) /
> [工程规范](../conventions/) / [契约真源](../ROS2迁移交接文档.md#hard-constraints)）后再删。
> 约束仍只引用[契约真源](../ROS2迁移交接文档.md#hard-constraints)，本目录**不复述**约束。

<a id="lifecycle"></a>
## 1. 生命周期：**写完就删**

```
立项（写 plan 文件） → 执行 → 结论归位（写进永久归宿） → 删除 plan 文件
```

| 阶段 | 允许做的事 | 禁止 |
|---|---|---|
| 立项 | 写一个 `docs/plan/<任务>.md`，只含**范围 / 出口判据 / 依赖** | 写约束条文（那是契约的事）；写会长期被引用的结论 |
| 执行 | 过程中更新 plan 文件；把**有用信息**随手记进永久归宿 | 让别的文档引用本目录 |
| 结档 | 逐条确认结论已归位 → 删除本文件 | 留着"以备将来"；留"历史记录"（那是 `docs/archive/` 的事） |

**判据**：任务完成后，删除 `docs/plan/<任务>.md` **不得产生任何断链**。
若会产生断链，说明结论没归位——**先归位，再删**。

<a id="where"></a>
## 2. 结论写到哪里（按信息类别，**唯一归属**）

| 信息类别 | 永久归宿 | 说明 |
|---|---|---|
| **难以逆转的决策**（选了什么、否了什么、为什么） | [`docs/adr/`](../adr/README.md#adr-index) | 一篇 ADR 一个决策域；含 Status / 背景 / 决策 / 不做什么 / Consequences |
| **工程规范**（怎么做的规则、口径、命名、分层） | [`docs/conventions/`](../conventions/) | 按主题一份；不复述契约 |
| **不可变约束 / 坐标系 / 终态语义 / 接口语义** | [契约真源](../ROS2迁移交接文档.md#hard-constraints) | 唯一约束来源；下游**只引用、不复述** |
| **能力边界 / 已知限制** | [根 README「已知边界」](../../README.md#已知边界当前能力范围) | 解读结果的前提；写"不成立的范围" |
| **可执行的判据** | `tests/` / `src/*/test/` | 结论固化为测试；测试比文档可靠 |
| **排障知识**（症状 → 根因 → 修法） | [`docs/conventions/整链排障速查.md`](../conventions/整链排障速查.md) | 按症状可搜 |
| **过程编排史**（当年按什么顺序推） | `docs/archive/` | 只留**不可替代**的；过程叙事不留 |

**反例（不得写入任何地方）**：任务内的临时 TODO、逐轮汇报、被后续决策推翻的中间结论、
"某轮试过但失败"的过程细节—— 除非它**解释了一个仍然生效的决策**，那就写进该 ADR 的 Consequences。

<a id="writing"></a>
## 3. 写 plan 文件的最小结构

只写四段，**不写更多**：

```markdown
<a id="goal"></a>
## 目标 # 一句话：做完什么、为谁服务
<a id="scope"></a>
## 实施边界 # 明确不做的事（比做什么更重要）
<a id="exit"></a>
## 出口判据 # 可判定：怎么算完成；不可判定的判据等于没写
<a id="deps"></a>
## 依赖与并行 # 前置、资源（是否独占仿真）、能否并行
```

**不写**：背景长篇、方案对比、逐日计划、验收清单的复述—— 这些要么属于 ADR，要么属于执行记录。

<a id="discipline"></a>
## 4. 纪律

- **一次只推进一个任务链**；独立链并行须**用户授权**（[协作边界](../../.coordination/README.md#parallel)）。
- **先学后做**：查参照的优先顺序见 [AGENTS.md](../../AGENTS.md)（项目内同版本可运行实现 → 社区同类 → 外部搜索）。
- **未决事项不得静默假设**：要么挂到对应任务，要么进 ADR。
- **不弱化**：契约红线、独立验收、失败证据留痕（[协作协议](../../.coordination/README.md#protocol)）。
- **失败如实登记**：`TIMEOUT` 就是失败（契约）；不得用"接近成功"等措辞。

本目录只放临时 plan 文件，结档即删。
