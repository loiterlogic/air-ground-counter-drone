# 后续任务占位 · 空中障碍物真值地图传递

> 状态：后续方向记录；空中到地面的该数据链与共享格式尚未定型。

## 意图

由无人机侧取得障碍物真值，将障碍物信息整理为地图形式并发送给小车。未来视觉算法产生的障碍物地图也应采用可共用的表示。

## 现状线索

- 仓内已有真值派生障碍物配置与 `/agc/map` 地图输出（[map_adapter.cpp](../../src/agc_perception/src/map_adapter.cpp#L20-L32)）。

- 本任务记录的是障碍物真值数据链，不等同于障碍物视觉识别；既有视觉障碍物需求另见[ADR-0009 R2](../adr/0009-perception-truth-derived-and-vision-path.md#b2)。
