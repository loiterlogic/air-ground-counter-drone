# 后续任务占位 · 小车地图全局规划

> 状态：后续方向记录；规划算法未选择。

## 意图

小车取得障碍物地图后，使用地图进行全局路径规划。初期算法留待调研后选择一个简单方案；后续再接入同学提供的规划算法。

## 现状线索

- 当前默认占位规划器从车辆位置到目标位置生成几何直线路径，不使用地图；仅有无遮挡直达条件下的占位规划（[ADR-0013](../adr/0013-ground-planning-path-contract.md#top) (l)）。
- 既有 `ground_baseline` 使用 Nav2 Navfn 与 costmap，属于当前对照实现，不代表本任务已选择该算法（[baseline.yaml](../../src/agc_ground/config/baseline.yaml#L20-L28)）。

## 已裁定（用户 2026-10-31 / R1，见 [ADR-0013 (n)](../adr/0013-ground-planning-path-contract.md#ruling-r1-r3)）

**终局形态不是本文件决定的**——用户已裁定：全局路径规划**最终由外部独立节点提供**
（对方交付形态是**独立 ROS 节点**，**不是**本仓内部实现、**不是** Nav2 插件）。
本仓须预留可替换接入缝，使该节点到货后能在**不改任务层、不改 9 消息 ABI、不改唯一执行口**的前提下接入。

**但**：「外部节点到货即可零改动替换」是被**明确否定**的表述——ADR-0013 (m) 的四项对外接口未决项
确认前，该 ADR 只约束**当前占位阶段**。

## 待调研与决定

**只剩**：初期占位规划器换成什么算法（当前是几何直连占位，不消费地图），
以及地图接入（`/agc/map` → costmap）的落地方式。
"最终由外部独立节点提供"已定，**不是**待定项。

⚠ 已知缺口（2026-11-04 核对）：`/agc/map` 链末端当前只有 `ground_baseline` 消费，
而它只在 `command_source=baseline` 时启动 ⇒ 默认 `rl` 模式下**地图无人消费**。
属"路径规划"主线的待建部分，见 [路线分支治理](../conventions/路线分支治理.md#rule) 5.3。
