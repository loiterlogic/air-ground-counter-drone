# 逐格元数据（2026-11-11 新增；temp.md 方向一 / 方向四 A+B）
#
# **为什么需要它**：`/agc/map` 与 `/agc/map/evidence` 都是 `nav_msgs/OccupancyGrid`，
# 它的 `data` 每格只能装**一个 int8**。于是 temp.md 要的
#
#     占据比例：0.31
#     平均置信度：0.78
#     最近观测：0.2 s
#     来源：障碍实例 17
#     是否完整可见：false
#
# 一个都装不下 —— 只能退化成"这一格算 0 还是 100"。这正是 temp.md 指出的
# 表示能力上限：一个格只能回答二值决策，回答不了"这一格只有 31% 被占"。
#
# **为什么是新话题而不是改 OccupancyGrid**：`OccupancyGrid.data` 的宽度是消息定义
# 固定的（`int8[]`），改不了；而把五个量塞进一个 int8 是编码谜题，不是表达。
# 新消息是"加"不是"改"，与 ADR-0041 新增 `ObstacleFootprintArray` 同一先例。
#
# **为什么用并行数组而不是每格一个嵌套消息**：与 `ObstacleFootprintArray` 的点级
# 并行数组同一纪律 —— 下游按同一个下标读，不需要搬数据、不需要嵌套类型。
# 400×400 = 16 万格，五个并行数组的序列化开销远低于 16 万个嵌套 struct。
#
# **约定**：所有并行数组长度必须等于 `width × height`（行主序，与 OccupancyGrid 同序）。
# 空数组 = 本发布端不提供该信息（下游按"无信息"处理，**不得**当成 0）。

std_msgs/Header header          # 与同拍 /agc/map/evidence 同一时刻；frame_id=world
	builtin_interfaces/Time stamp
		int32 sec
		uint32 nanosec
	string frame_id
uint32 width                    # 列数
uint32 height                   # 行数
float32 resolution              # 格宽（m）
float64 origin_x                # 左下角世界坐标 x（m）
float64 origin_y                # 左下角世界坐标 y（m）

# ---- A. 几何占据图（temp.md 方向四 A）----
# 这一格**有多少比例被障碍覆盖**（0..1 连续值），不是"算不算占据"。
#
# 与 `OccupancyGrid.data` 的根本区别：`data` 回答"这一格算不算占据"（二值决策），
# 本字段回答"这一格被占了多少"（面积占比）。
# **它才是几何重建的评价口径**：拿规划层的二值占据去比精细真值，
# 会把"合理的边界离散化"记成感知误差。
#
# 口径：粗格内被判为占据的细格数 / (factor × factor)。
# 分母**固定**为 factor²，不是"已观测的细格数" —— 后者会让"只看了一角且那角有障碍"
# 得到 1.0，与"整格被占"无法区分。
float32[] occupancy_ratio

# ---- B. 感知置信图（temp.md 方向四 B）----
# 这一格的判断**有多可靠**（0..1），与"占了多少"是两件不同的事：
#   * 占据率 0.25 + 置信度 0.90 ⇒ "这里确实有障碍，只是面积小"
#   * 占据率 0.25 + 置信度 0.30 ⇒ "这里可能有障碍，但只被弱观测过"
#
# 口径：格内 log-odds 证据离"中性"的距离，按观测次数归一。
# 它是**声明值**（不是识别置信度），与 `confidence.hpp` 同一纪律。
float32[] confidence

# ---- 最近观测（temp.md 方向一）----
# 距最后一次正向 hit 的**时间**（s）。-1 = 从未被观测到。
#
# **为什么是时间不是帧号**：帧号随帧率漂移（实测 6–10 Hz），"30 帧前"在 6 Hz 下是
# 5 s、在 10 Hz 下是 3 s —— 那不是可比较的量。时间才是。
float32[] last_seen_s

# ---- 来源实例（temp.md 方向一）----
# 该格最近的占据证据来自哪个障碍实例（-1 = 无归属）。
#
# **为什么不复用 `/agc/obstacles` 的字符串 id**：那是逐帧临时 id，
# 而这里要的是"这一格**现在**归谁"，是稳定的格级归属。
# 用 int32 是因为格数 16 万，字符串会让消息大一个量级。
int32[] source_instance_id

# ---- 是否完整可见（temp.md 方向一）----
# 1 = 该格完全在可信测量范围内且不在遮挡阴影里；0 = 部分/完全不可见。
#
# **为什么需要**：`unknown` 有两种完全不同的成因 ——
# "没看过"（覆盖问题，不是算法错）与"看到了但看不清"（遮挡 / 画幅边缘）。
# 混成一个 -1 就无法判断该怪谁。这个布尔把两者分开。
uint8[] fully_visible

# ---- 实例可见性状态（temp.md 方向三）----
# 与实例层同口径：本拍被观测到的已确认实例 id 列表。
# 消费者据此判断"这个实例现在还在被看着，还是只是历史残留"。
int32[] visible_instance_id
